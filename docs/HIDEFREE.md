## 一 ── 設定 → データ。「CSVの取り込み」が点線の箱で並んでいた ✔ 直した

**どう見えていたか。**設定 → データ を開くと、画面のまんなかに**点線で囲った
角丸の箱**が一つありました。中に ✧ の印、「CSVの取り込み」という見出し、その下に
**「表計算でまとめて作った単語を取り込む」という説明の二行**、右端に**青い枠の
`PLUS` という札**。無料ではこれしか無く、部屋はこの箱ひとつで終わっていました。

**設定の一覧にも出ていました。**設定を開くと「データ」という行の右端に、値として
**`Free`** と書いてありました。プランの行の `Free` とは別で、こちらは
**「この部屋は無料です」ではなく「この部屋は無料だと使えません」の意味**で
出ていました。

**押しました。**箱を押すと、画面ごとプランのページへ移ります。

**当たっていた決まり。**空の枠・灰色の行として見せている（9/4）。説明文が
二行ある（アプリ内に説明書くの禁止）。点線とはいえ**角丸の箱**で、`PLUS` の札
も枠付き（9/1 の 角丸やめろ）。**そして無料と有料で名前が違っていた** ──
無料は「CSVの取り込み」、有料は「リストの取り込み」。

**直したこと。**箱の分岐を消して、**有料と同じ `.set` の一行**にしました。
言葉は有料と同じ `set.csv.in`（「リストの取り込み」）、右端は同じ `›`。
**設定一覧の右端も `Free` をやめて、有料と同じ `CSV`** にしました。
押すと有料へ行くのは今まで通りです ──「扉は押したら飛ぶ」OWNER 2026-09-03。

`.lock` の CSS 一式（点線・角丸・`PLUS` の枠）は誰も着なくなったので消し、
`tools/box-baseline.txt` の四行と、十言語ぶんの `set.lock.csv.t`
`set.lock.csv.d` も一緒に消えています。

**スクショ。**`shots/before,after/1-set-data-{free,paid}-ja.png`。
直したあとは無料と有料が一枚の絵として同じです。

## 二 ── リストの取り込み。ボタンの文字が「ファイルを選ぶアップグレード」に化けていた ✔ 直した

**どう見えていたか。**リストの取り込みの画面の下に、金色の一行があります。
無料だと **「ファイルを選ぶアップグレード ›」** と読めました ──
**「ファイルを選ぶ」と「アップグレード」が、間を空けずにくっついて一つの
語のように並んでいました。**有料だと同じ場所が「ファイルを選ぶ」だけです。

**押しました。**押すと画面ごとプランのページへ移ります。

**当たっていた決まり。**文字の並びがそのまま読めない。
**押せない物を見せるより、読めない文字を見せる方が悪いです。**
**そして幅と寄せも違っていました** ── 有料は画面いっぱいの真ん中、
無料は自分の言葉の幅だけの左寄せ。

**直したこと。**末尾の `up.cta` の付け足しをやめて、**有料と同じ
「ファイルを選ぶ」の一語**だけにしました。無料の側にも `.impfile` を着せて、
**幅も寄せも有料と同じ**にしました（`.impfile` は display:block・width:100%・
text-align:center で、中の `input` の行は有料の面だけのものなので
`.impfile input` のまま動いていません）。押すと有料へ行くのは今まで通りです。

**スクショ。**`shots/before,after/2-import-{free,paid}-ja.png`。
