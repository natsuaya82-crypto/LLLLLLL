# claude/keep ── 保存していないまま画面を出ようとしたら、この app のポップで訊く

### Scope

- **Goal:** 打った内容がその場で保存されている画面を、**打っている間は憶えるだけ**
  の形に**書き換える**。変えたら右上に保存のボタンが出て、保存せずに出ようとしたら
  `popAsk()` が「入力内容を保存しますか？」と訊く。はいなら保存して戻る、いいえなら
  保存せずに戻る。**一つの仕組みで、画面ごとに書かない** ── 画面を出る道は
  `back()`（`www/shell.js`）一箇所で、左端のスワイプもそこを通る。

- **Decision it implements:**
  `docs/FEATURE_RULES.md` § Owner decision log
  「保存していないまま画面を出ようとしたら、この app のポップで訊く」（2026-09-03）

- **Owns (may change):**

    `viewReset()`）

## 対象の画面 ── コードを読んで数えた

数え方は二つ。**`IN(...)` / `CH(...)` で受けた値が、その関数の中で直に
`save*()` を呼んでいるもの**と、**`openForm()` で開く、打ち込みのあるシート**。

### A ── 今、打った瞬間に保存されている。**書き換える**

| # | 画面 | route | 欄 | 今の書き込み先 |
|---|---|---|---|---|
| A1 | プロフィール | `form:me:` | 名前 `meSetName` / @ `meSetHandle` / 自己紹介 `meSetBio` / リンク `meSetLink` / 場所 `meSetLoc` | `saveMe()` を一文字ごと |
| A2 | 文字 | `letter` | メモ `ltSetNote` | `saveLetters()` を一文字ごと |
| A3 | 世界（編集） | `world` | 居るところ `wldSet('where')` / 人 `wldSet('who')` / 概要の行 `wldOvSet(id,'k'\|'v')` / 節の本文 `wldArtSet(r,'b')` | `saveWld()` |
| A4 | 記事の一節 | `wldart` | 題 `wldArtSet(id,'t')` / 本文 `wldArtSet(id,'b')` | `saveWld()` |
| A5 | キーボード | `kb` | 名前 `kbSetNm` | `saveKb()` を一文字ごと |
| A6 | 文法の段 | `gram` | 規則 `stSetRules` / メモ `stNote` | `saveStg()` を欄を離れるたび |

### B ── 既に「憶えて、ボタンで保存」。**ポップを足し、ボタンを「変えたときだけ」にする**

| # | 画面 | route | 欄 | 今 |
|---|---|---|---|---|
| B1 | 文字の名前 | `letter` | `ltDraftName` → `ltDraft` | 右上 `ltSave` が常に在る。**A2 と同じ画面なので一つの buffer にする** |
| B2 | メモ | `form:note:<i>` | 題 `nt-t` / 本文 `nt-b` | DOM に憶えて右上 `saveNote`。常に在る |
| B3 | 単語のシート | `form:edit:<hw>` | 見出し・意味・品詞・語源・注・タグ | `wEdit` に憶えて `saveWord`。常に在る |

### C ── 対象外。理由を書く

| 画面／欄 | なぜ外すか |
|---|---|
| 検索の欄（`wordsSetQ` `ltSetQ` `ipaSetQ` `ntSetQ` `snsSetQ` `fSetQ`） | 保存されていない。`viewReset()` が忘れる画面の状態 |
| パスワード・メール（`setPwSet` `obMailSet` `adminSet` `adminStaffSet`） | 保存されない。押した瞬間にサーバーへ行って消える |
| 投稿の作成（`pwSetLn` `pwSetMn` `pwMarkText` `pwMarkSize`） | **既にオーナー決定の訊き方を持つ**（`BACKQ` / `backQHTML()`、OWNER 2026-08-25「下書きに保存しますか？」）。四つ目を作らないので触らない |
| 読み込みの貼り付け欄（`f-csv`） | 押して初めて読む。打った内容は保存先を持たない |
| 印刷シート（`shTyped`） | 保存されない下絵 |
| オンボーディング（`www/onboard.js`） | `claude/door` の持ち物。扉は別の形 |
| 段の例を足す欄（`sx-*`）／自作の段（`st-t` `st-w`） | 「保存」ではなく「足す」。押して初めて物になる |
| 新しい単語のシート（`addW`） | 同じく「追加」。`addOne()` は断ることがある |
| 文字の絵（`geSave`）・顔の写真（`mePicAsk`） | 打ち込みではない。絵と写真は自分の保存を持つ |

**C の下二つは、保存せずに出ると今も黙って捨てます。**この決定の言う
「保存」ではなく「追加」なので外しましたが、**外したことを報告に書きます。**

## 「変わったか」を何で判定するか

画面を開いた瞬間の値（`was`）と、今欄に入っている値（`v`）を、**欄ごとに文字列で
比べる**。一つでも違えば「変えた」。

- 打って消して元に戻したら**変えていない**。だから訊かない
- 欄が正規化するもの（@ は小文字化して `[a-z0-9_]` 以外を落とす）は、
  **正規化した後の文字列で比べる** ── 欄に映るのがその文字列だから
- 比べるのは**打ち込みの欄だけ**。押して切り替わるもの（品詞、関係、絵、写真）は
  今のまま、押した瞬間に効く。**混ざっていないこと**を `keep-check` が持つ

## @ には事情がある ── 決めたこと

`www/me.js` の @ はサーバーが断ることがある（重複、そして 2026-09-03 に決まった
14日の制限 ── これは未実装で `claude/me3` の持ち物）。**保存を押しても保存されない
場合がある。**

**決めたこと: 保存は「効いたら戻る」。効かなかったら戻らない。**

- 保存を押すと、@ が変わっているときだけサーバーに訊く
- 断られたら **toast で断りを言い、画面に留まる。**打った内容はそのまま欄に残る
- 訊けなかったとき（signal が無い）は**断らない** ── 今の
  `meHandleSee()` の決定のまま。保存して戻る
- ポップの「はい」も同じ道を通る。**効かなかったら戻らない**

理由: 戻ってしまうと、断られたことが伝わらない。オーナーは 2026-08-25 に
「断る文章と実際に断ってほしい」と言っている。

**14日の制限そのものはこの枝では実装しない** ── サーバー（`supabase/schema.sql`
の `profile_rename()`）で止める決定で、私はその file を持っていない。
断りが返ってきたときに**留まる**道だけを用意する。

## キーボードの戻る一歩

`kbNoted()`（`www/keyboard.js`）は `JSON.stringify(b.lay)` だけを見ていて、
名前 `b.nm` は見ていない。だから**名前を打っても履歴は積まれていなかった。**
buffer にすれば `saveKb()` 自体が保存の一回だけになる。
**`keep-check` に「名前を打っても `KBU.u` が伸びない」「保存一回で `saveKb` 一回」
の二つを置く。**

## `viewReset()`

打ちかけの buffer は `viewReset()`（`www/shell.js`）で忘れる ── 言語が変わる／
全部消える、の二つ。他の言語を開いて前の言語の打ちかけが残っているのは、
`viewReset()` が在る理由そのもの。

2. **文字の画面の「保存」が、無料プランでも出ます。**`can('letters')` で隠して
   いましたが、隠していたのは名前の欄のためで、メモの欄は無料でも在ります
