## 1. 測ったこと（2026-09-10、CODE CONFIRMED ── headless、偽サーバー）

回した台本は `tools/again-check.mjs` の偽サーバー（`netSend` だけを差し替えた
もの）の上。**r11 の写しの欠陥は踏んでいません** ── あちらは `SERVER` の生の
ファイル文字列を `eval` して `=eq\\.` という正規表現を作っており、GET が毎回
`[]` を返していました。ここではテンプレートリテラルとして評価して取り出し、
`${` が無いことを確かめてあります。

### 再現した

| | |
|---|---|
| A ── 一台目（fixture の言語）がサーバーへ | letters **39** 行 |
| B ── 索引だけ・写し（`.got`）無しの端末、起動後 | 端末 LETTERS **38**、サーバー 39 |
| B ── 文字を一つ描いて保存 | サーバー letters **42** |
| 増えた三行 | `lt.k`／`l1`、`lt.t`／`l2`、`lt.qm`／`l4` |

**同じ名前の文字が二つずつ並びます** ── `k` が二行、`t` が二行、`?` が二行。
消えた行はありません（増えるほう）。描いてあった六行はどちらの側でも残ります。

### どの関数のどの行か ── 「同じ文字か」を二箇所が別々に答えている

| どこ | 何で答えているか | この言語での答え |
|---|---|---|
| `www/letters.js:645` `have[String(ltName(LETTERS[i])\|\|'').toLowerCase()]=1` → `:648` `if(have[c]) continue;` | **名前**（`ltName()` ── `nm` → 数字の値 → `ab` → `snd` を繋いだもの） | `l1` は `snd:['k']` なので名前が `k`。**「k の枠は埋まっている」** → `lt.k` を作らない |
| `www/letters.js:539` `ltSlotKey()` ── `var ab=String((l && l.ab)\|\|'')` | **`l.ab` だけ** | `l1` に `ab` は無い。**「枠ではない、別の文字」** |

`syOneOf()`（`www/sync.js:111`）が訊くのは後者です。枠でないと答えられた行は
`syKeyOf()`（**id**）に落ち、id が違い、両方に線があるので
`syPut()`（`www/sync.js:151`）の `out.push(x)` が二行目を足します。

**`ab` を書くのは二箇所だけです** ── `ltStart()`（`www/letters.js:651`
`l.ab=c`）と、綴りの箱（`:957`）。一覧から入れた文字（`www/import.js`）、
書き取りの紙（`www/sheet.js`）、オンボーディングで描いた文字
（`www/onboard.js`）、音から作った文字（`www/letters.js:1145`）は **`ab` を
持ちません**。fixture の五文字はその形で、実機に有りうる形です。

### なぜ写しの無い端末だけなのか（起動の順を測った）

```
netTook の前: LETTERS=38  LSL letters=38 行   ← ltStart() が空の文字表に作った
GET slice kind,no,at  kinds=all
GET slice body        kinds=words+lines+script   ← letters は要求されない
起動おわり: 端末 LETTERS=38  LSL=38 行
```

`www/net.js:1894`（`netLangsWalk` の `fill`）は「持っているものは飛ばす」ので、
`ltStart()` が先に 38 行を書いた時点で**サーバーの 39 は降りてきません**。
だから保存の合流は 38 対 39 になります。写しのある端末では `slRd()` が 39 を
返すので `ltStart()` は一枠も作らず、39 対 39 で何も起きません。

### ついでに測った ── 今の `ltSlotKey()` は「三十八のうちか」も外している

fixture の言語（39 文字）で `LETTERS.filter(ltIsBase).length`：

| | |
|---|---|
| 今（`l.ab`） | **35**。消せる行は `l1(k)` `l2(t)` `l3(-)` `l4(?)` の四つ |
| 名前で訊くと | **38**。消せる行は `l3` 一つ（＝三十九番目） |

OWNER 2026-09-02「a-z 0-9 !?に1からナンバリングしてそれ以降に追加されるのは
消す」「39以降は消せるんだよね？」と一致するのは後者です。

### 潰したこと

- **合流そのものは正しい。** 枠の id が両側で揃っている言語（`ab` を持つ
  三十八だけの言語）で同じ台本を流すと、38 対 39 は **39** で、増えません。
  増えるのは `ab` を持たない行がある言語だけです。
- **`syMerge()` の欠陥ではない。** `syPut()` が二行を足すのは「両方に線があり、
  id が違い、枠が違う」ときだけで、それはこの関数の仕事です。間違っているのは
  **枠を訊かれた `ltSlotKey()` の答え**です。
