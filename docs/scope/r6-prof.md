  全部読み込んでから開くんじゃないの？」

## 仕様（OWNER 決定 2026-09-07）

プロフィールは、出す物が**全部揃ってから**開く。押してから揃うまでは前の画面の
ままで、揃った瞬間にプロフィールが出る。くるくるは出さない。前の値を先に見せて
後で差し替える道（b7f5bce3「フォロー／フォロワーの数は回さない ── 前回の値、
無ければ語だけ」）は終わり。

## 測った（ヘッドレス、netSend1 を差し替えて全部の答えを 120ms で返す）

起動 → プロフィールが最初に描かれるまでに返っていた答え: **なし**。

| 時刻 | 描画 | 数字 | 非公開 |
|---|---|---|---|
| 164ms | profile | 無し | 無し |
| 172ms | profile | 2 / 1 | 無し |
| 330ms | profile | 2 / 1 | 出る |

数字はフォローの二本（`/rest/v1/follow?select=…`）が返った後、非公開は言語の
スライス（`/rest/v1/slice?select=…` → `netLangsDown()` → `langLoad()`）が
返った後。**印を描く行は消えていない**（`wldRow()` の `.wldoff` は在る）。
出ないのは `WLD` がまだ空だから。
