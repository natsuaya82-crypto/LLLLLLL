# claude/fil — 右上の絞り込み、二つ

「右上の絞り込みだけどホームと同じ文字にするのやめて少し小さく、そして絞り込みに
今日のお題追加して」 OWNER 2026-08-28

## 触るもの
- `www/index.html` （`.navq` の角の CSS だけ。`.phead` にも `.kbk.cell` にも
  触らない ── どちらも別のセッションが持っている）
- `tools/press-check.mjs` （主張の追加だけ）

## 触らないもの
- `www/sns.js` ── **`claude/other` が持っている**。`snsFilTop()` と `vFilter()` は
  どちらもそのファイルの中。リーダーへ一行返して待つ
- `www/net.js` ── お題の投稿を引く関数が要るが、それを呼ぶ側が `sns.js` の中なので、
  呼び手のいない関数は `dead-check` で落ちる。`sns.js` の返事が来るまで触らない
- `www/i18n/*.js` ── 上と同じ。鍵を足しても着せる場所がない
- それ以外すべて

## やること
1. 右上の絞り込みの字を、見出し（`.navt`）と同じ大きさに見えないよう小さくする。
   CSS だけ。`.navq` そのものは動かさない（他の画面が着ている）
2. 絞り込みに「今日のお題」を足す ── **`www/sns.js` 待ち**

## 回す検査
`es5` `box` `face` `act` `dead` `i18n` `press`。`press` は最後に一度。
