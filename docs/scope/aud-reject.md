## 直すもの

1. **`PrivacyInfo.xcprivacy` が無い。**`AppleProvider.swift`（バイナリに入る）が
   `UserDefaults` を使い、その pod にも `ios/` にも一覧表が一枚も無い。
   緑のあとメールで断られる型 ── build 86 の `ITMS-90158` と同じ出方。
2. **キーボードの `RequestsOpenAccess`。触りませんでした。**紙の上の答えは
   「要らない」です ── 拡張は読むだけで、書き込みも通信もせず、Apple の既定の
   砂場は「書き込みを禁じ、読み取りは許す」で、ガイドライン 4.4.1 は
   「フルアクセスを要求せずに動くこと」を要求しています。**それでも落としません。**
   `docs/scope/aud-state.md` の Q3 に、既にオーナー宛の未回答の問いとして
   立っています。外して実際には読めなかった場合、キーボードは一つもキーが
   出ない状態になり、人が自分で戻す道もありません。Linux に Swift は無いので
   ここでは確かめられません。**実機で確かめる道はあり、新しいビルドは要りません**
   ── いまのビルドでフルアクセスを**切って**、キーボードに自作の字が出るか
   見るだけです。出れば `false` は安全で、`www/` の手順書からフルアクセスの段も
   同時に消せます。
3. **読み込み順を止めるものが無い。**`tools/order-check.mjs` を足す。
4. **`netDay()` が今日を訊いていない。**
