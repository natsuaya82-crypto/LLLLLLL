# claude/r23-sec ── 文法の頁の単位を「形」から「節」にする

枝 `claude/r23-sec`（`integ-0905` から）。オーナー決定 2026-09-11（リーダー経由、
「それで進めて」）。

## 何をするか

1. 「開いたらそんな分け方してるの意味わからない。**人称でまとめて設定できれば
   いいやん**」 ── 動詞の章を開くと 21 頁への入口が並ぶのをやめる。**頁の単位を
   「形」から「節」に変える。**
2. 「**日本語はちゃんとしてくれ**。主語で変わる形なんか聞いたことない。私たち
   なんか単語で設定したら終わり、俺は文法の話をしてる」 ── 行名は学校文法の用語。

## 画面の形

- 動詞の章は 5 行 ── 人称変化／時制／命令・条件・可能・〜しなければならない・
  〜したい／受け身・使役／否定と疑問（最後は今のまま `neg:v` `q:v` の 2 行）。
- 「人称変化」は **1 頁**。一人称単数／二人称単数／三人称単数／一人称複数／
  二人称複数／三人称複数 が見出しで並び、各見出しの下はその形の規則の一覧
  （❶❷…）か「作成」。表は頁に一つ、列＝形。例文は頁に一つ。`?` は節の分。
- 時制・命令・受け身も同じ。名詞の「複数形」、形容詞の「比較」も同じ関数。
- 規則を書く紙（`openFmr`）は今のまま。

## 節の表

`G2FM_CHAPS`（形→fm→品詞の 24 行）と `G2BOOK` の群の見出しを**一つの表**に。

| 節 id | 名 | 品詞 | 形 |
|---|---|---|---|
| `person` | 人称変化 | v | `p1s` `p2s` `p3s` `p1p` `p2p` `p3p` |
| `tense` | 時制 | v | `prs` `pst` `fut` `plp` `prg` `prf` |
| `mood` | 命令・条件・可能・〜しなければならない・〜したい | v | `imp` `cnd` `pot` `obl` `des` |
| `voice` | 受け身・使役 | v | `pas` `cau` |
| `neg` | 否定形 | v | `neg` |
| `q` | 疑問形 | v | `que` |
| `pl` | 複数形 | n | `pl` |
| `degree` | 比較 | adj | `cmp` `sup`（`side:'than'`） |

`g2Chaps()` は節ごとに一つの章を作る。**形ごとの章（`v2:p1s` 等）は消える**
（残さない）。`G2BOOK` の `has` は節 id の並びだけになり、群の `t` は消える
（見出しだったものが節の名になる）。

## もう一件 ── 章の例文の ＋ が効かない

hunt が見つけたバグ。`g2ChapEx()` は `DO('stExOpen',[id])` だが `openStEx()` が
`stBy(id)` で段しか受け付けないので、章の頁の ＋ は何も起こさない。**押して
測ってから**、例文の頁の入口を一つの問いにする。

## データ

**何も消さない。**`STG.fm` の規則も、その `fm` も `id` も、`WORDS` の `slot` も
そのまま。`STG.ex` も触らない ── 章の例文は今まで一件も書けなかった（上のバグ）
ので、章 id の下には何も無い。

## リーダーからの追加（2026-09-11、hunt #17）

「節の行は答えた後も右端が『—』のまま」 ── `g2ChapVal()` を足した。節の行の
右端は**その節の形のうち規則が書かれた数 / 形の数**（時制 2/6）。形で出来て
いない節は数える物が無いので「—」のまま（目次の「語形成」と同じ理由）。
`gramlang` §19 に claim 四つ、「—」に戻して赤を見た。写真
`gram-book-verb-ja.png`（0/6 0/6 0/5 0/2 1/1 0/1）と
`gram-book-snt-ja.png`（三つとも「—」）。

数えるのは**規則**であって「書かれたか」ではない ── 疑問形は疑問詞六語が
入っているので薄くないが、規則は無いので 0/1 と言う。

## リーダーへ ── 見てほしいところ

1. **動詞の章の三行目が二行に折り返す。**「命令・条件・可能・〜しなければ
   ならない・〜したい」はオーナーが言葉で指定した名なのでそのまま入れたが、
   一覧の中でその行だけ背が高い。短くしてよければ言ってください。
2. **語の表に列の見出しを付けていない。**列は上の規則の見出しと同じ順だが、
   升そのものはどの形か言わない。`www/index.html` はこの枝の担当外なので
   新しい CSS を足していない ── 必要なら別の枝で。
3. **名詞の章の三行目が「名詞」と出る**（`posLabel('n')`）。r20-book の
   引き継ぎ 7 と同じで、この枝でも直していない。
