枝: `claude/r136-rp`（`integ-0905` から）

触る: `www/home.js`（`pfList()` のリポスト部分だけ）、`tools/tl-check.mjs`、
`tools/fixture.mjs`（写真に顔が要る時だけ）、`shots/r136-*.png`、
`docs/CHANGELOG.md`（一行）、この頁。

触らない: それ以外全部。`www/sns.js` の `snsList()` は読むだけ、同じ形なら報告。

原因（リーダーが測定済み）: `pfList()` は `pfBoosts()` をサーバーの id で引き、
`postById()` は `sid` でも当たるので、この端末で書いた投稿は手元の id の写しが
返る。その後 `at[q.id]` と `bo[p.id]` を手元の id で引くので、リポストの行が落ちる。
