# claude/words ── 実機で見つかった単語まわりの四件（2026-09-05）

### Scope

- **Goal:** オーナーが実機で見つけた四件。**一件ずつ、緑になったものから押す。**

  1. **単語の一覧の選択が、画面を出ても残る。**「洗濯して前の画面戻ると
     選択画面がキープされたままや。流石に解除して欲しい。」OWNER 2026-09-05
  2. **意味の無い単語の行が「意味の追加」と出るのに、押しても追加されない。**
     「空欄でいいよ」OWNER 2026-09-05 ── 行は**空欄**にする。
  3. **品詞をもっと細かく。**「女性名詞とか細かく分けたい人いるでしょ多分、
     もっと細かく選択肢分けれないの？」OWNER 2026-09-05 ──
     **これは訊かれている。決めるのはオーナー。**案を `docs/reports/` に出して止まる。
     **実装しない。**
  4. **品詞の選び方を蛇腹に。**「これも蛇腹スタイルでwikiと同じように／
     名詞　>みたいに開くやつにしたいな」OWNER 2026-09-05 ──
     既にある蛇腹（`ABOPEN`、規則 20）に合わせる。新しい形は作らない。

- **Owns (may change):**
  - `www/words.js` ── 一覧の行、選択、絞り込み
  - `www/shell.js` ── `viewLeft()` / `viewReset()` の該当行と `POS`
  - `www/index.html` ── 単語の行の CSS（`.mn .nomn` など）だけ
  - `www/i18n/{en,es,pt,fr,de,it,ru,zh,ko,ja}.js` ── 鍵の増減だけ（規則 2）
  - `tools/word-check.mjs` ── この四件を押さえる主張
  - `docs/CHANGELOG.md` / `docs/reports/` / この冊子

- **Does NOT own:** それ以外すべて。名指しで ──
  - `www/wordsheet.js`（単語のページとシート。`words.addmn` を二箇所で使って
    いるが、オーナーが言ったのは**一覧の行**なので触らない ── 報告のみ）
  - `www/home.js` の記事（`ABOPEN` は**読むだけ**、蛇腹の形を合わせるため）
  - `www/net.js` `www/core.js` `supabase/schema.sql` `ios/`
  - `CLAUDE.md` と `docs/` の他の冊子

- **Check to run:** `npm run word`（`tools/word-check.mjs`）。
  **全ゲートは回さない ── リーダーの仕事。**速い方は作業中に回す。

- **Data:** 何も増えない。`wSel` はメモリの上の「どこに立っているか」。
  三件目は案だけで、保存の形は一行も動かさない。
