# r164-ex — 例文を書く所は一つの仕組み（単語の例文と文法の章の例文）

## やること
- 単語の例文（`wdOpenMore()`/`wdExOpen()`・`wdTakeFields()` の例文の半分・`wdExHTML()`・`wdDelEx()`・`wdExNew`）と
  文法の章の例文（`stExOpen`・`stExType`・`stExTake()`・`stExDone()`・`stExHTML()`・`stDelEx()`・`stExNew`）を消し、
  一つの形（欄・＋・取り込み・消す・保存のバッファへのつなぎ）を一度書く。違うのは「どこに入るか」だけ
  （単語は `w.ex`、章は `STG.ex`）── 各側はその置き場を渡す。
- 同じ振る舞い：Enter は改行、＋ は打った物を足して次の空の欄を開く、バーの保存も打った物を取る、
  打ったまま戻ると「保存しますか」、何も打っていなければ黙って戻る。人の言語（`langLocked()`）には欄を出さない。
- 保存されるものは変えない（単語 `{ln, gl}`、章 `{lb, ln, gl}`）。移行なし。
- `pua-check` G/H と `keep-check` が両方の場所に同じ主張を持つ。旧い道を戻して赤を見る。
