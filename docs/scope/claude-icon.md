## 仕様として読んだもの

1. オンボーディングで書いた最初の文字がアイコンになる ── これは良い。
2. それ以降、アプリがアイコンを勝手に差し替えることは無い。
3. ユーザーが自分で設定したアイコンが上書きされるのは、バグ。

**が、これは読んだだけの見立てで、報告に「原因」として書きません。**

## 追記 2026-09-05 ── 押しました。原因は確定です

**読んでいません。実際に走らせて、画面を見ています。**新しい電話から始めて、
オンボーディングの canvas に**マウスで線を引き**、`obDone()` → `obFinish()` を
通ってアプリに出て、そのあと文字を書き直したり足したりして、そのつど
アイコンを読みました。

| 押した順 | アイコン |
|---|---|
| 1. オンボーディングを出た直後 | 描いた文字の線 `[[220,148],[328,184],[580,400],…]` |
| 2. 自分でアイコンを設定した | 写真 |
| 3. 文字を**足した** | 写真のまま |
| 4. 最初の文字を**書き直した** | 写真のまま |
| 5. 自分のアイコンを消した | 線 `[[10,10],[20,20],[30,10]]` |
| 6. 最初の文字を書き直した | 線 `[[5,5],[600,600],[5,600]]` **変わった** |
| 7. 前に文字を一つ入れた | 線 `[[1,1],[2,2]]` **変わった** |

**オーナーの言う「勝手に変わる」は 6 と 7 です。**誰もアイコンに触っていないのに
変わります。スクリーンショット:

- `shots/icon-1-onboarding-ja.png` ── オンボーディングを出た直後（描いた文字）
- `shots/icon-2-after-redrawing-a-letter-ja.png` ── **文字を書き直しただけ。
  アイコンが別の形になっています**
- `shots/icon-3-person-set-their-own-ja.png` ── 自分で設定したあと
- `shots/icon-4-their-own-after-redrawing-ja.png` ── そのあと書き直しても変わらない

**分けて書きます。**「自分で設定したアイコンが上書きされる」ほうは、**今日の
コードでは再現しませんでした**（2〜4）。オーナーの一文の後半は、いまの作りが
そういうバグになる、という指摘として読みました。**再現したのは前半だけです。**

## 原因 ── `postAvatar()`（`www/post.js` 1654）

アイコンがどこにも**保存されていません**。呼ばれるたびに `LETTERS` を先頭から
引き直して、**その時点で線を持っている最初の文字**を返します。だから文字を
書き直す・前に足す・並びが動く、で毎回変わります。オンボーディングで描いた
文字が入っているのは「たまたまそれが先頭だから」で、**そこに固定されている
わけではありません。**

## ここで止まります ── 直す場所が一覧にありません

**`www/post.js` は、触っていい一覧にも、別セッションが持っている一覧にも
ありません。**直しは「アイコンを ME に一度だけ書いて、`postAvatar()` は
それを読むだけにする」で、`postAvatar()` の書き換えが要ります。

`www/me.js` と `www/onboard.js` だけで済ませる道は**二つとも捨てました。**

1. me.js 側に二つ目の「アイコンを決める関数」を作って me.js の呼び出しだけ
   差し替える ── `sns.js`・`net.js`・`post.js` は古いほうを呼び続けるので、
   タイムラインとサーバーへ送る顔だけがずれます。CLAUDE.md が名指しで禁じている
   「古いほうの穴を新しい仕組みで覆う」そのものです。**継ぎ足しです。**
2. `obFinish()` で描いた文字を画像にして `ME.pic` に入れる ── オンボーディングを
   これから通る人しか直りません。**既にアプリを使っている人の `ME.pic` は空**
   なので、その人たちのアイコンは今日と同じように動き続けます。しかも文字（線）
   が写真になるので、投稿が運ぶ顔とサーバーへ送る顔の中身が変わります。
   **直っていないうえに、別のものを壊します。**

**`www/post.js` の `postAvatar()` を書き換えていいか、一行ください。**
許可が出れば、その場で書き換え → バグを戻して該当チェックが赤くなるのを見て →
バグを取る、まで一続きでやります。
