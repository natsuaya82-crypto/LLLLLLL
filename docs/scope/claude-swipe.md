## 1. 画面左からのスワイプで戻る

オーナー（2026-09-03）:

> 画面左からスワイプで戻るのは下タブの画面はなくして欲しい。ホームを押した瞬間
> の画面、プロフィールを押した瞬間の画面はいらない。ホームから人の投稿行った時
> とかそう言う時にして欲しい。戻る時は半分のとこから右にスライドしたら戻るだけ
> らしいんだけど、ページを捲るみたいに戻るようにして欲しい。今スキップする

読み取れる三つ ── ⓐ 下タブ直後の画面ではスワイプで何も起きない ⓑ 戻る先がある
画面でだけ効く ⓒ 指に付いてページを捲る形 ── は**一つの原因**です。

`www/shell.js` の `swEnd()` に `!swLive` の枝があり、そこは「後ろの画面の絵が
残っていないときは、アニメーションせずに `back()` を呼ぶ」と書いてある。下タブ
を押した直後は `goTab()` が `NAV` を一枚にするので戻る先が無く、絵も無く、その
枝に入って**飛ぶ**。それが「今スキップする」。

**その枝を消す。** `swMove()` の `swPic` まわりも同じ一文に書き換える ──
**絵が無ければジェスチャは始まらない**。`swPic` は「絵が無いのはジェスチャが
無いことではない」という*今は間違っている*一文のために在る変数なので、変数ごと
消える。その段落のコメントも同じコミットで消す（「歴史とかいいから消せよ」）。

残るのは一文です: **後ろに画面があるときだけ指に付いて捲れ、無いときは何も
起きない。**

`swDraw()` / `swgo` の travel（`.22s ease-out`、後ろの画面は 1/3 の深さ）は
**触らない**。オーナーが「飛ぶ」と言っているのが上の枝のことなのか travel の
速さ・カーブのことなのかは、枝を消してから実機に出して確かめる順。見た目の
判断はオーナーのもの。

`swPrev()` が絵を返す条件は `NAVBK.r === navBackTo()`。下タブ直後にこれが外れる
のは**正しい**（戻る先が無いのだから絵も要らない）。「ホームから人の投稿へ入った」
後に絵が残るかは別に確かめる。

### 検査

`tools/press.mjs` の「the way back, dragged from the edge」の種 2 が、今は
**新しい決定と正反対の主張**をしている:

> with no screen kept to show, the gesture did nothing at all.
> No picture is not no gesture — it only drops the drawing.

これを、下タブを押した直後の**本当の状態**（`goTab('build')` のまま、`NAVBK` を
手で潰さない）に置き換え、**何も起きないこと**を主張にする。種 1（`build` →
`words` から戻れる、`swon` が着く）と種 3（真ん中から引いても戻らない）はその
まま。赤を見てから直す。

## 2. 一行の欄に改行が入る

オーナー: 「必要ないところで開業できるのやめて欲しい」（開業＝改行）。
プロフィール編集の名前・@・リンク・場所の欄が改行で縦に伸びるスクリーンショット。

原因: `www/shell.js` の `lnField()` が作るのは `<textarea rows="1">`。縦書きと、
描いた文字の高さに合わせて伸びるために `<input>` ではない。textarea は Enter を
受けるので、`lnField()` で作られた欄すべてに改行が入る。

**直すのは一箇所。** この app は markup に `on*=` を書かない（規則3）ので、
Enter の受け口は `www/act.js` の `KD` の delegated listener に既に在る。そこが
一箇所。`.lnin` を着ている欄では Enter は行を作らない、と書き直す。

守ること:
- **自己紹介（`me-bio`）は本物の複数行で、改行は残す。**あれは `lnField()` を
  通っていない素の textarea で `.lnin` を着ていないので、`.lnin` だけを対象に
  すれば自然に外れる。確かめる。
- 貼り付けの改行は**広げない**。オーナーが言ったのは Enter。理由は報告に書く。
- `lnFit()` の高さ計算は**触らない**。描いた文字と縦書きのためのもの。

### 検査

`press` に主張を足す: **`.lnin` の欄で Enter を押しても行が増えない**こと、
**`me-bio` では増える**こと。両方赤を見てから。
