## 三件

### 一件目 ── アイコンが勝手に変わる

「アイコン勝手に変わるのは何だ。最初の文字になるのはいいけど、それはオンボー
ディングを通ってかいたもじだけで、それ以降は勝手に変えないで。ユーザーが
アイコン設定したのに変えられるバグになる」 OWNER 2026-09-05

仕様として読んだもの:

1. オンボーディングで書いた最初の文字がアイコンになる ── これは良い。
2. それ以降、アプリがアイコンを勝手に差し替えることは無い。
3. ユーザーが自分で設定したアイコンが上書きされるのは、バグ。

**まだ押していません。**`5582149e` に押した結果がありますが、指示は「読んで
信じるな、自分で押して再現しろ」なので、自分で再現してから原因を書きます。
再現するまで、このファイルにも報告にも「原因」は書きません。

**`www/post.js` は上のどちらの一覧にも載っていません。**前のセッションはそこで
止まりました。自分で押した結果、直す場所が `www/post.js` の中だけになると
分かった場合は、**質問で止まらず**、何が足りないかを一行書いて一件目を置き、
二件目・三件目を先に緑にして push します。

#### 追記 ── 自分で押しました。再現します

前のセッションの結果は読みましたが、**信じずに自分で走らせました。**新しい電話
（`localStorage` が空、`SET.done` が false、線を持つ文字が 0 個）から始めて、
オンボーディングの canvas に**マウスで二本の線を引き**（`X` の形）、画面の
`obDone` ボタンを**押し**、ドアを通って `obFinish()` でアプリに出ています。
そこから先、**アイコンには誰も触っていません。文字だけを動かしています。**

| 押した順 | プロフィールのアイコン |
|---|---|
| 1. オンボーディングを出た直後 | 描いた `X`（`lt.a`） |
| 2. その同じ文字を**書き直した** | 斜めの一本線 **変わった** |
| 3. 別の文字を作って**前に置いた** | その新しい文字 **変わった** |
| 4. 自分でアイコンを設定した | 写真 |
| 5. そのあと文字を書き直した | 写真のまま |
| 6. 自分のアイコンを**外した** | **オンボーディングの `X` ではなく、3 の文字** |

スクリーンショット（プロフィール画面、日本語）:

- `shots/icon2-1-onboarding-ja.png` ── オンボーディングを出た直後。`X` が出ている
- `shots/icon2-2-after-a-letter-moved-ja.png` ── **文字を動かしただけ。
  アイコンが別の形になっている**
- `shots/icon2-3-their-own-ja.png` ── 自分で設定したあと
- `shots/icon2-4-after-taking-it-off-ja.png` ── 外したあと。`X` は戻ってこない

**分けて書きます。**オーナーの一文の後半「ユーザーがアイコン設定したのに
変えられる」は、`ME.pic` があるあいだは**再現しませんでした**（4〜5）。ただし
6 で、外した先に戻ってくるのは**その人がオンボーディングで描いた文字ではなく、
その時たまたま先頭にある文字**です。**再現したのは 2・3・6 です。**

##### 原因（押して確かめたもの）

`postAvatar()`（`www/post.js:1654`）は**アイコンをどこにも保存していません。**
`ME.pic` が無ければ、呼ばれるたびに `LETTERS` を先頭から見て、**その時点で
線を持っている最初の文字**を返します。だから文字を書き直す・前に足す・並びが
動く、で毎回変わります。オンボーディングで描いた文字が出るのは「たまたまそれが
先頭だから」で、そこに**固定されていません**。

##### 足りないもの（一行）

**直す場所は `postAvatar()`（`www/post.js`）で、そのファイルが触っていい一覧に
ありません。**

`www/me.js` と `www/onboard.js` だけで閉じる道はありません。オンボーディングの
文字を `ME` に一度だけ書いても、読む側（`postAvatar()`）が `LETTERS` を見続ける
かぎり何も変わらず、me.js 側に二つ目の「顔を決める関数」を置けば
`sns.js`・`net.js`・`post.js` は古いほうを呼び続けます。それは CLAUDE.md が
名指しで禁じている「**古いほうの穴を新しい仕組みで覆う**」で、継ぎ足しです。
**書きません。**

一件目はここで置き、二件目・三件目を先に進めます。
