# claude/docs — 書かれているものを、いまの仕様に合わせる

## Goal
`docs/` と `CLAUDE.md` の中から、**いまの仕様と違う文を見つけて消す。**

きっかけは、リーダーが古い記載を読んで勘違いし、オーナーに間違った説明をしたこと。
原因は文章のほうなので、消すのは文章。

## いまの仕様（`CLAUDE.md` の Online の節、および OWNER 2026-09-01）
- **サーバーが本体。**SNS も言語も全部サーバー ── 投稿・写真・声・下書き・
  ハンドル・表示名・プロフィール画像・反応・フォロー・ブロック・通報、そして
  **言語そのもの**
- **端末が持つのは、電波が無いときに動く写しだけ。**端末は物が住む場所ではない
- **端末のものとして残るのは三つだけ** ── 言語のバックアップのファイル、
  書き出した表、設定
- **プラン（課金）はアカウントのもの**（OWNER 2026-09-01「課金とアカウントと
  キーボードはアカウントに結びつく」）。設定の中に置くという書き方は古い
- **キーボードは言語の一部**なので、言語と一緒にサーバー

## Owns (may change)
- `docs/**/*.md` ── **`docs/CHANGELOG.md` を除く**
- `CLAUDE.md`
- `docs/reports/docs-2026-09-01.md`（新規・この枝の報告）
- `docs/scope/claude-docs.md`（この file）

### 触らない一つ
**`docs/CHANGELOG.md` は一行も書き換えない。**あれはその日に何が本当だったかの
記録で、`CLAUDE.md` が名指しで例外にしている。古い記載がそこに在るのは正しい。

## Does NOT own
それ以外すべて。名指しで:

- `www/**` ── コードは別の担当が同時に直している。一行も触らない
- `tools/**` ── 同上。検査の数や名前が docs と食い違っていても、**直すのは docs 側だけ**
- `supabase/**` ── 同上
- `ios/**`, `package.json`, `capacitor.config.json`

## やり方
`docs/` と `CLAUDE.md` を `localStorage` `端末` `phone` `device` `SET.` `lingua.`
で grep し、当たった文を読む。**「これは端末のもの」と書いてある文が、上の三つ
以外について書かれていたら、それは古い。**

消し方は `CLAUDE.md` の規則どおり ── **消す。**「これは歴史です」と前置きして
残さない。読まれるから。

**迷ったら消さず、報告の「迷ったもの」の欄に入れる。**「古いかもしれない」で
消すと、正しい文が消える。

## Checks
`npm run i18n` だけ。鍵は触らないので緑のはず。遅い二十は回さない
（`docs/SESSIONS.md`: セッションはゲートを回さない）。

## Report
`docs/reports/docs-2026-09-01.md` ── 消した文と、それがどこに在ったか。
迷ったものは別の欄に。
