**iPhone だけで出しておくのが安全な順番。**

## H-2. どこにも書かれていない値 ── セッションの寿命

「久しぶりに開いたらサインアウトされるのか、それは何日なのか」に、
**このリポジトリは答えを持っていません。** `supabase/setup.md` にも `docs/` の
どこにも無く、値はダッシュボードの `Authentication → Sessions` にしかありません。

Supabase の既定では、**更新の切符は古くなっても切れません** ── 一年ぶりに開いても
入れます。切れるのは既定を変えたときだけ（`Time-box user sessions` と
`Inactivity timeout` の二つ）。アクセストークンの一時間は別の話で、これは黙って
更新されます。だから「長く開いていないとサインアウトされる」は**既定では
起きません。** この報告に一度そう書いて、取り消しました。

**二つの値を見て `supabase/setup.md` に書くこと。** 書かれていない値は、
次に訊かれたときにまた推測されます。
