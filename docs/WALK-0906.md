## どう触ったか

`tools/shot.mjs` と `tools/press.mjs` と同じやり方で playwright を書き、ポート
8140/8141 で `www/` を出して `tools/fixture.mjs` の `seed()` を入れた。端末は
402×874、deviceScaleFactor 3。押すのは実際の click / touch で、`data-do` の名前
から一つの委譲リスナーを通る。指のいる画面は CDP の `Input.dispatchTouchEvent`
で触った（語順の板は touch イベントしか聞いていないので、マウスでは動かない）。
スクショは `shots/walk/`（コミットしない）。

**サーバーには届かない環境**。Supabase へ出る要求は全部落ちる。だから
`netPop()` の「接続がありません」が、こちらが何をしていなくても、見ている画面
の上に出てくる。**これはこのアプリの仕様であってバグではない**（オンライン専用、
CLAUDE.md 十一章）。ただし出ている間は `#sbg.on` が画面全体を覆うので、その下の
ボタンも字を描く手も届かない。下の記録では、押す前に必ずこのポップを閉じている。

**最初にこれで二回まちがえた**。ポップに邪魔された押下を「押しても何も起きない」
と読み、字を描いた線が消えたと読んだ。どちらも道具のせいで、アプリのせいでは
なかった。ポップを閉じてから押し直したら両方とも正しく動いた。

## 正しく動いたことの記録

- **字を描いて保存して開き直す**。文字の一覧 → 字 → 描く画面と押していき、
  カンバスに線を一本引いて［保存］。`ltById('lt.a').st` が 1 本になり、
  `SET.myfont` が true になり、一覧に戻って開き直しても残っている。保存の直後に
  画面は動かず（通信が落ちているので `keepSave()` が先へ進めない、これは
  2026-09-05 の決定どおり）、「接続がありません」が出る。
- **語順の板**。指で最初の札を三番目の位置まで運ぶと、並びが `S O V` → `O V S`
  になり、`STG` に書かれ、別の画面へ行って戻っても残っている。
- **単語を一つ足す**。綴りと意味を入れて［追加］で、その語と、規則が作る形が
  一緒に入る。上限の勘定も形の分を数えている。
- **書記体系の選択**（Plus）。選ぶだけでは変わらず、［保存］で `wsys()` が
  変わる。開き直しても残る。
