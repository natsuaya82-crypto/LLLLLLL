# 手で歩いた記録 — 2026-09-06

`master` を headless Chromium で人が触るように操作した記録。コードは直していない。
見たことだけを書く。**バグ 4 件、気になる 4 件。**

## どう触ったか

`tools/shot.mjs` と `tools/press.mjs` と同じやり方で playwright を書き、`www/` を
出して `tools/fixture.mjs` の `seed()` を入れた。端末は 402×874、
deviceScaleFactor 3。押すのは実際の click / touch で、`data-do` の名前から一つの
委譲リスナーを通る。指のいる画面は CDP の `Input.dispatchTouchEvent` で触った
（語順の板は touch イベントしか聞いていないので、マウスでは動かない）。
`page.on('pageerror')` と `console.error` は全部拾った。スクショは `shots/walk/`
（コミットしない）。

このコンテナには外へ出る網が無いので `netPop()` が「接続がありません」を出す。
**アプリの仕様どおりの動きなので、下には書かない**（リーダーの指示、2026-09-06）。
ただしそのポップは `#sbg.on` で画面全体を覆うから、下のボタンにも字を描く手にも
触れなくなる。だから seed の直後に `window.netPop=function(){}` を入れて黙らせ、
その上で押した。

**この道具のせいで最初に三回まちがえた。**ポップに邪魔された押下を「押しても何も
起きない」と読み、描いた線が消えたと読み、投稿画面の戻るが効かないと読んだ。
三つとも道具のせいで、アプリのせいではなかった。**下の四件は、ポップを黙らせた
状態でもう一度確かめたものだけ。**

### 再現手順

**1.** 言語のページを開く（`world`）。二十章のとおり節は全部閉じて出る →
「Overview」の行の右の ＋（`wldOvAdd`）を押す → 画面は変わらない。`world().ovs`
だけ増えている → 「Overview」の行そのものを押して開くと、増えた空行が溜まって
いる。**先に節を開いてから ＋ を押した場合は行が見えて増える（正しい）。閉じて
いるときだけ、押した人には何も起きていないように見える。**

**2.** Plus で単語を 105 個にする → free に落とす → 設定 →「Your language」。
`www/settings.js:209` が `WORDS.length`、`:211` が `LETTERS.length` を出している。
行の先の画面は `wordsSeen()` と `ltSeen()` を出す。**「105 / 100」は、上限を書いて
いるその行が上限を超えた数を出している。**

**3.** free のまま検索タブ（`find`）を開く。`ltSeen()` が隠している `l1`〜`l4` が
`fPick` の札に出る。押すと、その文字で辞書が絞られる。

**4.** 文法 → Plural → 下の「4 words」。一回目 `WORDS` 11→15、二回目 19、三回目
23。作られた 12 語は全部 `fm:'pl'` を持っている。**二回目が食べたのは一回目が
作った語**。作られた語自身は複数形を持たないので、ボタンの数はいつまでも 4 の
まま。free の 100 語の天井を、押した回数だけ削る。

## 正しく動いたことの記録

- **字を描いて保存して開き直す**。文字の一覧 → 字 → 描く画面と押していき、線を
  一本引いて［保存］。`ltById('lt.a').st` が 1 本になり、`SET.myfont` が true に
  なり、開き直しても残っている。
- **語順の板**。指で最初の札を三番目まで運ぶと `S O V` → `O V S` になり、`STG` に
  書かれ、別の画面へ行って戻っても残っている。
- **単語を一つ足す**。綴りと意味を入れて［追加］で、その語と規則が作る形が一緒に
  入る。上限の勘定も形の分を数えている。
- **書記体系**（Plus）。選ぶだけでは変わらず、［保存］で `wsys()` が変わり、開き
  直しても残る。
- **投稿・スレッド・返信・いいね**。投稿を押すとスレッドが開き、返信の相手が
  正しい（他人の投稿に返信すると相手の名前が出る。自分の名前ではない）。
- **下書き**。書きかけで戻るを押すと画面の中に「Save this as a draft? ／ Save ／
  Discard」が出る（`BACKQ`、`www/shell.js`）。［Save］でトースト「Saved as a
  draft」、下書きの一覧に出る。空のまま戻るを押すとそのまま戻る。
- **辞書の検索**。`tir` で 11→5 行、`zzzzz` で「Nothing found」、×で 11 に戻る。
- **キーボードの編集**（Plus）。行の番号を押して選び、ゴミ箱でその行が消え
  （41→31 マス）、一つ戻すで戻り、進めるでまた消える。
- **設定の各部屋**。lang / look / acct / data / ui、全部開いて中身が出る。

押した。free / plus / pro の三回、69 画面・491〜500 押下。ネットのポップを
黙らせた状態でもう一度回して、同じ数だった。

- 例外を投げたもの: **0**

- 押しても画面も `#sheet` も `#pop` もトーストも一切変わらなかったもの:
  free 108 / plus 111 / pro 112

その中身はほとんどが変わらなくて正しいものだった: `sayPh`（音を鳴らすだけ）、
`clearSearch`（空の検索欄）、`geUndo`/`geRedo`/`geClear`（何も描いていない紙）、
`keepPress`（何も変えていない画面）、`plBuy`/`storeRestore`/`storeManage`
（StoreKit がブラウザに無い）、すでに選ばれているものをもう一度選ぶもの
（`setUi ["en"]`、`pfSetTab ["posts"]`、`wsPick ["syll"]`）。**そこから手で
確かめて残ったのが上のバグ 1 と 4。**
