# お題で絞る ── 三つのやり方と、いま画面がどうなっているか

リーダーへ。オーナーの「今日のお題のハッシュタグってないの？ないならフィルターに
追加して欲しい。」に答えるための紙です。**決めるのはオーナーです。**ここには、
いま何が在るか、と、取れる形が三つ書いてあるだけです。

---

## いま在るもの

**ハッシュタグは在りません。**一つも。押して確かめました ── タイムラインの
一番上の「今日のお題」の行が出す画面の中に、`#` の付いた語は一つもありません。
投稿にタグを付ける仕組みも、タグで探す仕組みも、このアプリにはありません。

**代わりに在るのは、見えない繋がりです。**お題の行から書き始めた投稿には、
「どの日のお題に答えたか」が最初から付いています。目に見えないので画面には
出ませんが、消えることもありません。**これは 2026-08-23 にオーナーが決めた形
です** ──「繋がりはハッシュタグではなく列。文字列は編集で切れるが、列は切れない。」

**絞り込みは今三つです。**タイムラインの右上を押すと開く画面に、
「おすすめ」「フォロー中」、そしてその下に⭐️で保存した言葉が並びます。
**お題の行はありません。**

---

## 取れる形 ── 三つ

### 1. 絞り込みに「今日のお題」の一行を足す

- **操作。**タイムラインの右上を押して絞り込みを開くと、「おすすめ」「フォロー中」
  の下に、その日のお題の文がそのまま一行で並んでいる。それを押す。
- **画面。**タイムラインが、その日のお題に答えた投稿だけになる。右上には
  お題の文が出るので、いま何を見ているかが分かる。
- **押すと。**同じお題に答えた投稿が、新しい順に並ぶ。他の日のものも、
  お題に答えていないものも出ない。書いた人が本文をどう直しても外れない。

  **今日のぶんだけです。**昨日以前のお題は、いまアプリの手元に無いので選べません。
  「昨日のお題」まで並べるなら、それは別の作業になります。

### 2. ⭐️ で保存する言葉として扱う

- **操作。**検索の画面でお題の文を打って⭐️を押すと、絞り込みの一覧にその文が残る。
  次からはそれを押す。
- **画面。**⭐️で保存した言葉の一覧に、お題の文が一行増えるだけ。新しい仕組みは
  何も増えない。
- **押すと。**その文が本文に入っている投稿が並ぶ。**同じお題に答えた投稿でも、
  書いた人の表示言語が違うと出てきません** ── お題は人によって十の言語で
  出るので、日本語で保存した文は英語で書いた人の投稿に当たりません。

### 3. 本当にハッシュタグを足す

- **操作。**お題から書き始めると、投稿の本文にその日の合言葉が一語入る。
  それを押すと、同じ合言葉の投稿が並ぶ。
- **画面。**投稿の本文に、押せる一語が増える。他の人の投稿にも見える。
- **押すと。**同じ語が入っている投稿が並ぶ。**ただし本文の一部なので、書いた人が
  消せます。**消された投稿はその日のお題から外れます。これは 2026-08-23 に
  オーナーが「切れない方にする」と決めたのを覆すことになります。

## 一つだけ、外の人に頼むことがあります

**1 番を選んだ場合**、「その日のお題に答えた投稿を集めてくる」問い合わせが
一本要ります。それはサーバーとやりとりする側のファイルにあって、いま別の人が
持っています。絞り込みの画面そのものは私の持ち場です。

**2 番と 3 番は、外に頼むものはありません。**

# もう一件 ── 押しても何も起きない 🔍

お題とは別の話です。**オーナーの「検索してもツイート出てこないよ」の原因は
これです。**

**どの画面の、どこにあるボタンか。**

検索の画面（下のタブの真ん中、虫めがねのタブ）です。上の帯の中に検索欄があり、
**その左端に虫めがねの印が付いています。**幅も高さも 15。

**押すと今どうなるか。**

**何も起きません。**別の所へ行くこともなく、エラーも出ません。押した、という
ことすら記録されません。押して測りました ── 画面は「人をさがしている」状態の
ままで、投稿を探す問い合わせは一本も出ていきません。

投稿を探す道は、**電話の改行キーを押すことだけ**です。それを押せば投稿は
ちゃんと出ます（測りました。一件書いて、打って、改行キーで一件出ました）。
オーナーは 2026-09-03 に「検索は🔍押したらって言ってるやん」と言っています。
その 🔍 が、押せる形になっていません。

**直すのに必要なもの ── 三箇所。どれも私の持ち場の外です。**

1. **`www/shell.js` の `searchBox()`。**虫めがねをここで
   `<span class="lens">` として描いています。押せるものにするなら、この一箇所。
   **六つの画面が共有しています**（辞書・文字・IPA・目次のさがす・検索・音）
   ので、**呼ぶ側が名前を渡したときだけボタンになる形**にしてください。
   他の五画面は打つそばから絞り込むので、押すものは要りません。
2. **`www/act-map.js`。**押されたときに走らせたい名前は `snsGo` で、これは
   いま**改行キーの表にしか登録されていません**（`actKey('snsGo', snsGo)`）。
   押すボタンから呼ぶには `act('snsGo', snsGo)` の一行が要ります。
   無いまま `data-do="snsGo"` を書くと `act-check` が落ちます。
3. **`www/index.html`。**`.search .lens` が今の見た目です。`.sx`（✕ と ⭐️ が
   着ている class）と同じ形にできるなら、新しい CSS は要りません。
   **角丸も枠も足さないでください**（規則 18）。

`www/sns.js` の側（`snsFieldHTML()`）は、名前を渡すだけで済みます。**pop が
1 と 3 を、`act-map.js` を持つ人が 2 を入れてくれれば、私はその日に
`tools/find-check.mjs` に一行足して押さえます。**

**それまで、この 🔍 を止めているものは何もありません。**`tools/find-check.mjs`
の 7 番は `snsGo()` を直接呼んでいるので、画面の 🔍 が死んだまま緑になります。

## もう一つ、小さいが同じ場所の話

検索欄の下書きの文字が「さがす　@で人」です。これは「ふつうに打つと投稿が出る、
@ を付けると人が出る」と読めますが、**コードは逆です** ── ふつうに打つと人だけが
出て、投稿は改行キーを押すまで出ません。十言語ぶんの言葉なので `www/i18n/` の
十本、これも私の持ち場の外です。**言葉づかいはオーナーのものなので、直す前に
何と書くかを訊いてください。**
