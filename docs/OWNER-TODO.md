## 一 ── **いま一番大事。サーバーのバックアップ**

**Supabase の管理画面で、そのプロジェクトのバックアップが入っているか見てください。**
入っていれば、**どこまで遡れるか**も。

**確かめたこと:** `supabase/setup.md` に、バックアップについての記述が
**一行もありません**（`backup` `PITR` `バックアップ` を検索して 0 件）。
入れたのか入れていないのか、記録が残っていません。**2026-09-04 確認。**

**なぜ一番大事か。** サーバーが本体で、SNS の分（投稿・下書き・プロフィール・
フォロー）は**サーバー一箇所にしかありません。**それが普通で、X もインスタも
同じです ── **あちらが消えないのは、運営がサーバーごとバックアップを
取っているからです。**

そして 2026-09-04 に「消えないための仕組みを一本にする。サーバーに版を積む」と
決まりました。**サーバーが全部を持つなら、土台がこの一枚です。ここが無ければ、
何を積んでも意味がありません。**

- [ ] 入っているか見た
- [ ] 入っていなかったので入れた
- [ ] どこまで遡れるかを `supabase/setup.md` に書いた
