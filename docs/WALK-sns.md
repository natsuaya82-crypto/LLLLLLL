### 再現手順

**1. スレッドはブロックを見ていない。**
タイムライン → iri の投稿の「…」→［Block］。フィードから iri の投稿は消える
（正しい）。→ 自分の投稿を押してスレッドを開く → **iri の返信がそこにある。**
逆からも同じで、自分の返信 p4 のスレッドを開くと、間にいる iri の投稿が親として
出る。行の `data-do` を数えると、ブロックあり `p1 p3 p4`、ブロックなし `p1 p3 p4`
で同じ。

`vThread()`（`www/sns.js:1528`）の頭には「Blocked is gone, not merely absent from
the list」と書いてあり、`postBlocked(p)` を見ているのは**そのスレッドの主の投稿
だけ**。上（`postUps`）と下（`postDown`）の行は `postGone()`（＝取り下げ）しか
見ていない。`postBlocked()` と `postGone()` は別のもの（`www/post.js:118` と `:152`）。
ブロックした人の投稿を直接開く（`thread:p2`）と「That is no longer here.」になる
ので、**入口が一つだけ塞がっていない。**

**2. 空の文字欄が画面からはみ出す。**
投稿画面 → 写真を一枚選ぶ（本物のファイル欄 `#pw-cam` から入れて確かめた）→
写真の文字ボタン（`pwMarkOpen`）→ 下のバーの ⒜（`pwTool ["mark"]`）。
**この時点で、まだ一文字も打っていない。**
測った値：ステージ（写真）は 402×268 で y=303。入力欄 `#mk-tx` は
`y=-26 / w=44 / h=927 / font-size:90px`。画面は 874px なので上にも下にもはみ出す。
「ka」と打つと `y=386 / w=103 / h=103` になって写真の中に収まる。二文字消すと
また `y=-26 / h=927` に戻る。

`pwMarkFit()`（`www/post.js:2315`）の数字がそのまま出ている。幅は
`Math.max(44, pwMarkWide(m)*bw+4)` で、印が空なので 44。字の大きさは
`m.s*bw*1.25 = 0.18*402*1.25 = 90.45` → 90px（空文字だと `at100` が 0 なので
測り直しの行を通らない）。高さは `e.scrollHeight` で、**幅 44px の箱に 90px の
プレースホルダを流し込んだ高さ**が 927px。つまり**欄の大きさは「打った文字」で
測り、画面に出ているのは「プレースホルダ」**で、その二つが別物になっている。

［Done］を押すと `{tx:'', x:0.5, y:0.5, s:0.18, c:'--mk0'}` という**中身の無い印が
写真に残る**（`PW.pics[0].marks`）。`pwMarkTrim()` はあるが、この道では通らない。

**3. 断られた保存が、もう書いてある。**
プロフィール →［Edit］→ 名前を `Aya2` に変える →［Save］。通信が無いので保存は
通らず、画面は編集のまま残る（アプリ本体ではここで「接続がありません」のポップが
出る。これは仕様）。→ 戻るを押す →「Save what you have typed?」→［No］。
→ **プロフィールは `Aya2`。** `ME.name` は［Save］を押した時点で既に `"Aya2"` に
なっている。

同じ画面で、［Save］を**押さずに**戻って［No］を押すと `Aya` のまま（正しい）。
違いは［Save］を一度押したかどうかだけ。二つ並べて測った：

| したこと | ［No］の後の `ME.name` |
|---|---|
| 名前を打つ → 戻る →［No］ | `Aya` |
| 名前を打つ →［Save］（断られる）→ 戻る →［No］ | `Aya2` |

`keepSave()`（`www/shell.js:443`）のコメントが、そうなる理由を自分で書いている
――「`b.save` has written the fields to this phone by now」。サーバーが受けたか
どうかを訊くのはその後で、断られても端末に書いた分は戻らない。この関数は
**九つの画面が通る一本道**だとそのコメントに書いてあるので、プロフィールだけの
話ではないかもしれない（他の八つは触っていない）。自己紹介の欄でも同じことが
起きるのは見た。

**4. 凍結が半分しか効いていない。**
`NET_BANNED` を立ててフィードを開くと、タイムラインの代わりに
「Account suspended / Posting, replying and liking are off. /［Appeal］」が出て、
書くための＋も消える（正しい）。そのまま自分のプロフィールへ行くか、投稿を押して
スレッドを開くと、**返信・ブースト・いいねのボタンがそのまま在る。**

- いいねを押す → ハートが点いて `postById('p1')` が `{li:1, lime:true}` になる。
- 返信を押す → 投稿画面が開く（`form:post:`、返信先も付いている）。

＋（`openPost`）はどの画面からも消えているので、**塞がっているのは「新しく書く」
一つだけ**で、画面が「返信といいねも止まっている」と言っている二つは止まって
いない。

## 正しく動いたことの記録

- **フィードの二つ**。右上から `filter` へ行って「For you／Following」を選び直せる。
  選んだほうにチェックが付き、戻ると `snsTab` がそのままになっている。フォロー中は
  自分の投稿と iri・veth の投稿だけ、おすすめは返信を外した一覧。
- **保存した言葉での絞り込み**。`filter` の KEPT から「ka」を押すとフィードの見出しが
  「ka」になり、答えが来ていないので「No connection.」が出る（三状態のうち真ん中で、
  正しい）。もう一度 `filter` を開くとその語にだけチェックが付いている。
- **投稿**。文と意味を打って［Post］。**投稿は一つだけ増え、二重にならず、消えもしない。**
  投稿画面は空になり、もう一度開いても空。送れなかった旨のポップの後も同じ。
- **返信**。他人の投稿から返信すると、上に出るのは**相手の投稿**で、できた投稿は
  `{to:'p1', toh:'aya'}` を持ち、元の投稿の返信数が 1→2 になる。自分の名前は出ない。
- **リアクション**。いいね・ブーストとも、押すと点いて数が 1、もう一度押すと消えて 0、
  三度目でまた 1。自分の投稿でも他人の投稿でも同じ。
- **投稿のメニュー**。自分の投稿は［Pin／Edit／Delete］、他人のは［Block／Report］。
  「…」をもう一度押すと閉じる。削除は「Delete this post?」と訊いてから消し、
  トーストが出て、スレッドの子は残る。
- **ブロックと解除**。ブロックすると相手の投稿がフィードからもその人のページからも
  消え、「…」が［Unblock］になり、押すと戻る。
- **下書き**。書きかけで戻ると「Save this as a draft?」。［Save］でトーストと一覧への
  追加、開き直すと本文も `did` も戻る。開いた下書きは一覧から外れる（二重防止）。
- **通知**。ベルの数字は 1 で、通知を開くと `SET.notAt` が書かれ、別のタブへ移ると
  数字が消える。通知の行を押すとその投稿のスレッドが開く。
- **検索の履歴**。return で `SET.recent` の先頭に入り、×で欄を空にすると履歴の一覧に
  戻る。一件ずつ消すボタンもある。
- **カード**。他人の投稿のカードが、その投稿が持っている ink で描かれる。縦書き
  （`dir:'ttb-rl'`）も右の列から。16:9 / 1:1 / 9:16 の三つとも切り替わる。
- **右スワイプで戻る**。スレッド・他人のプロフィール・写真・投稿画面、どれも左端から
  引くと戻る。書きかけの投稿画面では、戻る前に下書きの問いが出る。
- **下タブをもう一度押す**。フィードで押すと一番上まで戻り、スレッドやよその
  プロフィールから押すとその根の画面に戻る。
- **声**。マイクの無い機械では「The microphone is not allowed」、ファイルの無い声は
  「That voice is missing」。どちらも黙って落ちない。
- **サインアウトした顔**。feed / explore / notif / profile の四つとも扉になる。
- **通報の反対側（`mod`）**。三種類の行（まだ出ている投稿・取り下げ済み・アカウント
  についての通報）が出て、［Dismiss report］は「Delete this report?」と訊いてから消す。
  通信が要る操作なので、ここでは押しても何も変わらないところまでしか見ていない。
