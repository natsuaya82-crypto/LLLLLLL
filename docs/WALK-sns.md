### 再現手順

**1.** タイムライン → iri の投稿の「…」→［Block］。フィードから iri の投稿は
消える（正しい）。→ 自分の投稿を押してスレッドを開く → **iri の返信がそこにある。**
逆からも同じで、自分の返信 p4 のスレッドを開くと、間にいる iri の投稿が親として
出る。押した行の `data-do` を数えると、ブロックあり `p1 p3 p4`、ブロックなし
`p1 p3 p4` で同じ。

`vThread()`（`www/sns.js:1528`）の頭には「Blocked is gone, not merely absent from
the list」と書いてあり、`postBlocked(p)` を見ているのは**そのスレッドの主の投稿
だけ**。上（`postUps`）と下（`postDown`）の行は `postGone()`（＝取り下げ）しか
見ていない。`postBlocked()` と `postGone()` は別のもの（`www/post.js:118` と `:152`）。
ブロックした人の投稿を直接開く（`thread:p2`）と「That is no longer here.」になる
ので、**入口が一つだけ塞がっていない。**

**2.** 投稿画面 → 写真を一枚付ける → 写真の「文字」ボタン（`pwMarkOpen`）→ 下の
バーの ⒜（`pwTool ["mark"]`）を押す。**この時点で、まだ一文字も打っていない。**
測った値：ステージ（写真）は 402×268、y=303 にある。入力欄 `#mk-tx` は
`y=-26 / w=44 / h=927 / font-size:90px`。画面は 874px なので上にも下にもはみ出す。
「ka」と打つと `y=386 / w=103 / h=103` になって写真の中に収まる。二文字消すと
また `y=-26 / h=927` に戻る。

`pwMarkFit()`（`www/post.js:2315`）の数字がそのまま出ている。幅は
`Math.max(44, pwMarkWide(m)*bw+4)` で、空の印なので 44。字の大きさは
`m.s*bw*1.25 = 0.18*402*1.25 = 90.45` → 90px（空文字だと `at100` が 0 なので
測り直しの行を通らない）。高さは `e.scrollHeight` で、**幅 44px の箱に 90px の
プレースホルダを流し込んだ高さ**が 927px。つまり**欄の大きさは「打った文字」で
測り、画面に出ているのは「プレースホルダ」**で、その二つが別物になっている。

［Done］を押すと `{tx:'', x:0.5, y:0.5, s:0.18, c:'--mk0'}` という**中身の無い印が
写真に残る**（`PW.pics[0].marks`）。`pwMarkTrim()` はあるが、この道では通らない。
