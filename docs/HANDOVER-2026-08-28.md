**これが引き継ぎ書の本体だ。** 上の一覧は git を読めば分かる。これは分からない。

1. **コードを読んだだけで「直っています」と言った。** 何度もやった。
   オーナーは実機を持っている。**読みは根拠ではない。** 測るか、動かすか、
   スクショを撮るか。私が最後にまともに仕事をしたのは、空の localStorage で
   アプリを起動して「扉が出る」を実際に見たときだけだった。

2. **確認せずにスクショを送った。** 起動画面が被った**真っ白な絵**を
   「これが証拠です」と言って送った。**撮ったら自分で開いて見ること。**
   `await pg.waitForSelector('#splash', {state:'detached'})` を `goto` の
   直後に入れないと必ずこうなる。

3. **古い枝で撮ったスクショを「直りました」の隣に出した。**
   帯が上下に分かれていないのを見せて、オーナーに
   「治ってないやんけ」と言われた。**何が入っている枝で撮ったのか確かめること。**

4. **終わっているオーナーの作業を二度訊いた。**「なんで終わってるやつを何回も
   言われんだよ」。`docs/STATE.md` に書いていなかったのが根本原因。
   **済んだことは日付つきで書く。書いていなければまた訊かれる。**

5. **規則を見当違いに持ち出した。** 「打つほど減っていく輪」に対して
   「角丸禁止」を持ち出して怒られた。**規則は当てはまるところにだけ当てる。**

6. **セッションに間違った指示を出して、あとから撤回した。** 三回やった

   毎回そのセッションの作業が無駄になった。**配る前に、オーナーの言葉を
