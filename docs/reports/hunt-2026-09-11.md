# アプリを人として歩いた ── 2026-09-11

枝 `claude/r21-hunt`（`integ-0905` の `f7789038` から。報告の前に
`origin/master` の `29076d64` を取り込み、**全部の道を取り込んだ木で
もう一度歩き直しました** ── その日の master が文法の頁を 9 章＋付録に
組み直していたので、古い形で測った分は捨てました）。**直していません。**
見つけたものを並べただけです。決めるのはオーナーです。

## どう歩いたか

`tools/hunt.mjs`。**ゲートの検査ではありません**（`npm test` にも
`package.json` にも入れていません）。検査は「書いた通りか」を訊きますが、
これは訊きません ── 画面を開き、押し、打ち、戻り、もう一度開いて、
出てきたものを写真に撮ります。

- **憶える偽サーバー**（Node 側）。PostgREST の形（`select` `eq.` `in.`
  `is.null` `order` `limit`、`Prefer: return=minimal` と
  `resolution=merge-duplicates`）、`profile_seen` `post_seen` `follow_seen`
  `language_seen` の四つの view、`feed_hot` `feed_fo` `notices`
  `account_delete` ほかの RPC、`/auth/v1/*`、storage、`verify-plan`。
  **読みは `supabase/schema.sql` の policy と同じ形で絞ります** ──
  `draft` `saved_search` `recent_search` `block` `plan` `language_take` は
  持ち主だけ、`language` と `slice` は公開か持ち主か取った人だけ。
- **端末は browser context 一つが一台。** 同じ偽サーバーに二台つなげます。
- 一歩ごとに `shots/hunt/NN-<端末>-<何>.png` と、同じ名前の `.txt`
  （画面の言葉・打ち込み欄の中身・トースト・ポップ・シート）。
  **写真は全部こちらで開いて目で読みました。**

走らせ方：`node tools/hunt.mjs` （道を選ぶなら `node tools/hunt.mjs 1 2 3`）。

## 対象外 ── ここでは確かめられないもの

- **iOS のキーボード拡張**（`ios/App/LinguaKeyboard/`）。実機だけです。
- **Apple の購入画面**（StoreKit）。同じく実機だけ。
- **声**。偽のマイクでは録れました（0:01 まで数えます）が、止めた瞬間に
  「声は保存できませんでした」と出ます。headless の codec の話か本物の
  バグかは**ここでは分かりません**。実機で一度押してください。
- **本物の Supabase**。偽サーバーの上を歩いたので、**サーバー側の policy の
  穴はこの枝では見つかりません**（`npm run rls` の領分）。

## 道具が作った偽物 ── 一度そう見えて、取り下げたもの

報告の値打ちは「本物だけが並んでいる」ことなので、外した三件も書きます。

1. **「消した文字が再起動で戻ってくる」** ── 保存は打ち終わって 1.2 秒後に

## 気になる（仕様かもしれません） ── 5 件

### 13. 型を選んで作ったキーボードは、キーが全部空　【仕様？】

- **道**（道5・有料）キーボード → キーボードを追加 → QWERTY。
- **画面に出たもの** `89-A-kb-editor.png`。形は QWERTY（10・10・9＋半キー・
  8＋delete・space と enter）。**キーの字は全部「·」。**
- **測った値** 無料の板 0 のキーは `{k:"lt", v:"lt.q", t:"q"}`。作った板は
  `{k:"lt", v:"", t:""}`。**五つの型ぜんぶ同じ**（QWERTY・フリック・タップ・
  音の表・**ABC順**）。
- **なぜ仕様かもしれないか** 型は「形」で、字は人が置くもの、という作りに
  見えます。**ただし「QWERTY」も「ABC順」も、どの字がどこに来るかの名前**
  なので、押した人は壊れていると読みます。決めるのはオーナーです。
