持っていたファイル: `www/letters.js` `www/sound.js` `www/phases.js`
（リーダーの指示で `docs/CHANGELOG.md` も）。

**埋めていたのは `ltStart` ではなく `sndStart()` でした。**`www/sound.js` の
一関数で、`SND` が空なら `asOrder(asSounds('plain', 12))` を書いていました。
それをやめました。**既にある音は一つも消していません。**

## 指示の訂正 ── ここが一番読んでほしいところです

指示は `ltStart` と `ltSetRoman` を名指ししていましたが、**`ltStart` は最初から
正しく、一行も直していません。**目録に触っていません（`l.snd` は文字の読みで、
`SND` ではありません）。`ltSetRoman` も正しく、人が読みを付けたときだけ足します。
**足していたのは三つ目の関数でした。**

もう一つ。**これは今日見つかった話ではありません。**`docs/CHANGELOG.md` の
「文字を消したら、その文字だけが読んでいた音も言語から出ます」の項が、末尾で
`sndStart()` の条件を変えるのは決めごとなので直していない、リーダーへ、
オーナーに聞くこと、と書き残しています。**その決定が下りた前提で作業しました。**
下りていないなら、ここで止めてください ── コードは push 済みですが、
取り込む前に外せます。

## 何をしたか

| file | 何を、なぜ |
|---|---|
| `www/sound.js` | `sndStart()` の中身を空にした。書いていた理由（新しい文字が空いた音を取る）は**今のコードに無い** ── `ltNew()` は `snd:[]` を作り、文字が勝手に音を取る道は残っていません |
| `www/sound.js` | `sndDropLoose()` の上のコメント。次の起動で12個に埋め直される、と書いてあったのが嘘になったので直した |
| `docs/CHANGELOG.md` | 記録。**コードより先に**書いて別コミットで push |
| `www/letters.js` `www/phases.js` | **触っていません。**`phases.js` は音に一切関わりません |

## 振る舞い

- 新しい言語: `SND` は空のまま。起動でも言語を開き直しても埋まりません
- アルファベットの画面: 新品の言語に出ていた鉛筆のセル（`sndLoose()` ── 言語が
  持っていてどの文字も読んでいない音）が**出ません**。あれは人が置いたものでは
  なくアプリが置いたものでした
- 全部の文字を消した人（Plus / Pro）: ゼロがゼロのままになります

## やり残し ── 全部、持っていないファイルです

1. **`sndStart()` は何もしない関数として残っています。**呼び手は `www/core.js`
   （`langOpen`）、`www/boot.js`（2）、`www/settings.js`（2）の5箇所。関数ごと
   消すにはその5行を一緒に消す必要があり、**先に消すと起動で落ちて端末が
   真っ白になります。**
2. **`www/assist.js` の `asSounds()` を誰も呼ばなくなりました**（`AS_CHARS`
   `asChar()` `asReal()` も、`asSounds` が消えれば次の回に出ます）。
   `sndStart()` が唯一の読み手でした。`npm run dead` の赤はこれです
3. **`tools/migrate-check.mjs`** の4番目のブロックが
   `want('and sounds to start from', addedSndLen(c.snd) > 0, true)` で、
   **規則違反そのものを緑で固定していました。**上のコメントの理由（音の無い
   言語は全部の文字が何も読まない言語だ）も、今のコードには残っていません

①②③は一つの直しの三つの端で、**同じ人が一度に片付けるのが安いはずです。**
