## だから直したのは一箇所、そして「書けなかったとき」の話です

```
前: 電話が resolve すれば               →「書き出しました」
今: 電話が**ファイル名を返して初めて**  →「書き出しました」
    名前が無ければ                      →「ファイルの保存先に届いていません。」
```

**なぜ名前かというと、こちら側にある証拠がそれしかないからです。** Swift の
`sheet` は `try bytes.write(…)` に成功したときだけ `url.lastPathComponent` を
返し、他の道は全部 `reject` します。ブリッジ無し・reject・名前の無い answer は、
**人にとっては同じこと**（Files に無い）なので、同じ一文を出します。

**これが指示の ⚠ に当たるところです。** この章が人を傷つけられる唯一の道が
「書けていないのに書けたと言う」で、そのとき人は Files を開いて、何も無くて、
これから描くはずだった文字がどこにも行かない。

`shMake()` の上のコメントも直しました ──「There is no Swift behind `sheet`
yet」と書いてありましたが、sheet3 が入れたので**もう嘘**でした
（`CLAUDE.md`「a change lands with every sentence it falsifies」）。
