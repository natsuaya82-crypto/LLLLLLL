## 0. プロフィールの写真が `profile.av` に届かなかった原因（測った）

本番: tytaymcgill は `profile.ed {}`・`profile.av null`、2026-09-24 の投稿は `body.av.pic` を持つ。

**測り方**: 当時の版（公開 1.0.0 = ビルド 162 `982197a4`、TestFlight 165 `7873029d`、
写真の道は同じコード）の `www/` を実ブラウザで開き、`netSend` だけ差し替えて要求を記録した
（`mePicKeep()` で写真を選ぶ → `postAvatar()` → `bootSession()`）。

| 測った事 | 結果 |
|---|---|
| 写真を選んでから投稿するまでに出た要求 | **0 本** |
| 投稿が載せる顔 | `{"pic":"data:image/j…` |
| `profile` への PATCH | **次の起動（`bootSession()` の `netAvSync()`）で初めて出る** |

**原因 1（当時の版）**: 162/165 は写真を端末（`ME.pic`）に書くだけで、サーバーへは
**次のコールド起動**の `netAvSync()` でしか送らなかった。写真を選んで、アプリを
閉じて開き直さないまま投稿すれば、投稿には写真が載り、`profile.av` には何も行かない。
`ed {}` は、その版が `ed` を送らない（`ed` は 2026-09-23 `300da4c5` から）ことと合う。

**原因 2（166 以降に上がった時）**: 166 で `netAvSync()` を消し「押した時に送る」
（`meFacePut()`）に替えたが、**送られていない写真を上げる移行が無かった**。しかも
起動で `profile.av=null` を読むと `meAvGot(null)` が端末の写真を消す。今の版で測った:
`ME.pic` あり・サーバー `av null` で `netMyProfile()` → `ME.pic` は **GONE**。
その人の写真は 09-24 の投稿の `body.av.pic` にしか残っていない。

**今の版にも残る穴（原因 3）**: `meFacePut()` の成功側は `meAvGot(row? row.av : av)`
── PATCH が **0 行**（行が無い・`is_member()` が偽）で `[]` が返ると、送った写真を
端末に置く。測った: 0 行の答えで `ME.pic` は **表示される**、サーバーには何も無い。
`net.js` が「書いて何も変わらなかった物を、書けた物として読まない」と書いている
（`netSend1()` の Prefer の段）のに、`NET_PUT` の `got` が `null` を返し、呼び手が
成功として扱う。
