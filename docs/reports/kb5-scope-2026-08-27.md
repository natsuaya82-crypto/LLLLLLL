# リーダーへ ── `www/index.html` に入れてほしい三行（再掲）

`claude/kb4` `b79e88e` の写しです。詳細と測定値はそちらに。

**1. 行の隙間に名前をつける**（264行）

```css
/* いま */
.kb.kbsheet{width:var(--kbw);margin:2px auto 0;--kh:44px;gap:5px}
/* して欲しい */
.kb.kbsheet{width:var(--kbw);margin:2px auto 0;--kh:44px;--kbrg:5px;gap:var(--kbrg)}
```

**2. 行の高さを固定し、キーを伸ばさない**（271行）

```css
/* 足す */
.kb.kbsheet .kbrow{height:var(--kh)}
/* いまの行に align-self:start を足す */
.kb.kbsheet .kbk{min-width:0;margin:0 calc(var(--kbgap) / 2);align-self:start}
```

**これが要です。** 無いと grid の行が中身に合わせて伸び、下の行が 49.83px
押し下げられ、同じ行の隣のキーが 44.83 → 89.66 になります。測りました。

**3. すでにある高さの式を一般化する**（328行）

```css
/* いま */
.kbk{position:relative;min-height:calc(var(--kh) * var(--rh));min-width:0;
/* して欲しい */
.kbk{position:relative;min-height:calc(var(--kh) * var(--rh) + var(--kbrg, 0px) * (var(--rh) - 1));min-width:0;
```

**新しいセレクタは足しません。** 結合したキーには `keyboard.js` が
`style="--rh:2"` を書きます。`--kbrg` はシート以外の板では宣言されていないので
`0px` に落ち、そこは何も変わりません（43キー全部 52px のまま、測定済み）。

**盤ごと一つの grid にはしません。** 行の `<div>` が消えると
`.kbrow.sel::before` と `.kbhdr` が巻き添えになり、`index.html` を触っている
三本と衝突します。この三行なら今あるものは 1px も動きません。

**入るまで、画面では一行のままです。** それは想定どおりで、赤にはなりません。
