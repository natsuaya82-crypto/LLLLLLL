## 入れてほしいもの

**1.**（212行）行の隙間に名前をつける

```css
/* いま */
.kb{display:flex;flex-direction:column;gap:6px;margin:2px -20px 0;--kh:52px}
/* して欲しい */
.kb{display:flex;flex-direction:column;gap:var(--kbrg);margin:2px -20px 0;--kh:52px;--kbrg:6px}
```

**2.**（264行）シートの側にも

```css
/* いま */
.kb.kbsheet{width:var(--kbw);margin:2px auto 0;--kh:44px;gap:5px}
/* して欲しい */
.kb.kbsheet{width:var(--kbw);margin:2px auto 0;--kh:44px;--kbrg:5px;gap:var(--kbrg)}
```

隙間は板によって 6px と 5px で違うので、板ごとに宣言して名前は一つにします。
二行ぶんの高さは「キー2つ＋隙間1つ」なので、隙間の数を知っている必要があります。

**3.**（271行の直前に二行、足す）行の高さを固定し、キーを伸ばさない

```css
.kb .kbrow{height:var(--kh)}
.kb .kbk{align-self:start}
```

**これが要です。** 無いと grid（と flex）の行は中身に合わせて伸びるので、
キーを高くすると**行そのものが伸び、下の行が押し下げられ、同じ行の隣のキーまで
背が伸びます**。両方の板を覆うので `.kb.kbsheet` ではなく `.kb` で書いています。
キーボード一覧の行は `.kblist .kbrow` で `.kb` の中に無いので、当たりません。

**4.**（328行）すでにある高さの式を一般化する

```css
/* いま */
.kbk{position:relative;min-height:calc(var(--kh) * var(--rh));min-width:0;
/* して欲しい */
.kbk{position:relative;min-height:calc(var(--kh) * var(--rh) + var(--kbrg, 0px) * (var(--rh) - 1));min-width:0;
```

**新しいセレクタは足しません。** `--rh` はもう `.kbk` が読んでいる変数で、
`.kbrow` が `--rh:1` を置いています。結合したキーには `www/keyboard.js` の
`kbRhCSS()` が `--rh:2` を書きます。`--rh` が 1 なら `+ var(--kbrg) * 0` に
なって、今あるものは何も変わりません。

**盤ごと一つの grid にはしません。** 行の `<div>` が消えると
`.kbrow.sel::before`（行の帯）と `.kbhdr` が巻き添えになり、`index.html` を
触っている三本と衝突します。この四行なら構造は動きません。

## 入るまでどうなるか

**画面が崩れます。撮ってあります** ── `shots/kb5-vjoin-nocss.png`。
結合キーだけが伸びるのではなく、**その行のキーが全部二行ぶんの高さになり、
下の行に穴が空きます。** grid（と flex）の行が中身に合わせて伸びるからで、
測った 44.83 → 89.66 がそのまま目に見える形です。四行入れた側は
`shots/kb5-vjoin-css.png`。

**それでも赤にはなりません。** `press` の「一つの list は一つの高さ」は
`tools/press.mjs` 289行で**字の大きさが二種類あるときだけ**赤にし、伸びた行は
キーが全部同じ高さなので差も出ません ── 結合した面を fixture に入れた状態で
`press` は緑（11893、240/240）でした。**データも実機も正しいままです。**
崩れるのはこの編集画面の見た目だけで、直すのがこの四行です。

## 二つ、判断をお願いしたいこと

**1. 下の行が選ばれているとき、紫の帯が結合キーの下半分に掛かります。**
`.kbrow` は `position:relative` で z-index が auto なので重ね順は DOM 順に
なり、後にある下の行の帯が勝ちます。下半分はその行のものでもあるので**正しい
とも言えます。** 要らないなら `keyboard.js` の `kbRhCSS()` に `;z-index:1` を
足すだけで消えます ── `index.html` は要りません。**見てから決めてください。**

**2. キーボード一覧の縮小図（`kbShotHTML`）は、結合を一行ぶんで描きます。**
あれは `.kbsr`/`.kbsk` という別の class の別の絵で、`--rh` を読みません。
96px の縮小図なので**そのままにしてあります**。直すならもう一組 CSS が要るので、
要否はリーダーの判断です。
