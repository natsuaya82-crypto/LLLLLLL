> 「Googleはアカウント登録はこちらのギリギリで貼り付けて欲しい。
>   全部下に行けば扉もっとデカくできるでしょ」

## 絵

| file | 何 |
|---|---|
| `door-390x844-before.png` | 今 ── Google の下に 111px 空いている |
| `door-390x844-after.png` | 案を当てた ── 空き 8px、扉は 77×116 → **144×219** |
| `door-320x568-unchanged.png` | SE1。**before と after がバイト単位で同一** |

暗いテーマ・日本語・390×844（オーナーの機種の寸法）。

## 当てた CSS（`www/index.html`。二行だけ）

```css
.ob .mid.obform .obcrest{flex:1 1 auto}              /* 2724行を 0 1 auto から */
.ob .mid.obform .obcrest .obdoor{max-height:220px}   /* 2726行を 116px から */
```

**新しいセレクタは作っていません。** 既にある二つの値を変えるだけです。

なぜこれで下に寄るか: `.mid.obform` は縦の flex で、`>*` は全部 `flex:0 0 auto`。
紋章だけを `1 1 auto` にすると**余りを紋章が全部吸う**ので、その下の Apple /
Google / 帯は自動的に下端まで押し下がります。`margin-top:auto` を足す必要は
ありません。

## 測った数（暗・日本語）

| 画面 | 扉 前 | 扉 後 | 空き 前 | 空き 後 |
|---|---|---|---|---|
| 390×844 | 77×116 | **144×219** | 111 | **8** |
| 375×667 | 60×92 | 60×92 | 7 | 7 |
| 320×568 | 29×44 | 29×44 | 6 | 6 |

**小さい機種は動きません。**もともと余りが 6〜7px しか無いので、吸うものが
ありません。**退行はここには無い、というのが数字の意味です。**

面ごとに見ても、はみ出しはどこにもありません:

```
390×844 after   in 144x219   up 145x220
320×568 after   in  29x44    up 128x211
お忘れ / コード / 再設定 / 名前 ── 扉の絵がそもそも無い面（影響ゼロ）
```

登録の面（`up`）だけは小さい機種でも伸びます（77×116 → 128×211）。その面は
「お忘れですか」も区切り線も Apple も Google も出ないので、もともと余りが
大きいためです。オーナーの「全部下に行けば扉もっとデカくできる」に沿う方向です。

## 上限を 220px にした理由

`.obdoor svg` は `max-width:min(40vw,148px)` で幅も縛られています。扉の絵の
縦横比はおよそ 0.66 なので、**高さ 220px のとき幅は 146px** ── 148 の上限に
当たる直前です。それより高くしても幅で頭打ちになり、絵は大きくなりません。
