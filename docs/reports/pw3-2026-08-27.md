## 3. 作文画面の帯 (`ef670c4`)

### まず測りました

`www/shell.js` の `vvFit()` に `visualViewport` を差し替えて値を手で渡し、
`.pwbar` がどこに立つかを読みました。**実機ではありません** ── headless
Chromium にソフトキーボードは無いので、`resize` の連打そのものは再現でき
ません。**渡された値に対して `vvFit()` が何を返すか**だけを測っています。

390×844、キーボード 336pt。**直す前:**

| `visualViewport.height` | `--vvkb` | 帯の上端 |
|---|---|---|
| 844（上がっている途中、まだ知らされていない） | **0px** | **791** |
| 817 | 27px | 764 |
| 770 | 74px | 717 |
| 706 | 138px | 653 |
| 642 | 202px | 589 |
| 582 | 262px | 529 |
| 535 | 309px | 482 |
| 508（上がりきった） | 336px | **455** |

**オーナーの写真二枚は、この表の一行目と最終行です。** 帯は消えていたのでは
なく `bottom:0` ＝ **キーボードの裏**に居ました。**リーダーの読みは当たって
います。**

### 直したあと

同じ渡し方、二回目の開き:

| `visualViewport.height` | `--vvkb` | 帯の上端 |
|---|---|---|
| 844 / 817 / 770 / 706 / 642 / 582 / 535 / 508 | 336px（全部） | **455**（全部） |

**一度も動きません。** `resize` が一回しか来ない機種でも 455 のまま
（最後の二行だけを渡した場合）。

### やったこと

`--vvkb` に書くのは**その起動で測れたいちばん深い値**（`vvKbMax`）。欄に
文字を打てる状態でないときは 0 ── 帯は画面の底へ戻ります。一回目だけは
今までどおり下から上がります（一度も測っていないキーボードの高さは知りよう
がないので）。ただし最大しか採らないので途中で下がることはありません。

`--vvtop` と `--tabgap` は**一切変えていません。** 持ち上げ 40 のときの
`--vvkb` は直す前と同じ 296px、帯の上端も同じ 495 です。

**`www/index.html` は触っていません。CSS は要りませんでした。**
`.view.fit .pwbar{bottom:var(--vvkb)}` はそのままで、渡す数のほうを直して
います。

### 私が一度間違えた所

**覚える数と書き出す数は別です。** iOS は打っている欄をキーボードの上へ出す
ためにページのほうを持ち上げます（`offsetTop`）。キーボードは動いていない
ので、ページに貼りついた帯はその分だけ降りないと離れます。最初に書いた
版は持ち上げぶんを引いた数を覚えていて、**ページが持ち上がっている間じゅう
帯が 40 浮きました。** 測って出ました。覚えるのは 336、書き出すのは 336−40。

### 検査 ── 何も押さえていなかったので四つ足しました

`tools/post-check.mjs` §11d2。赤を四つとも見ています:

| 戻したバグ | 出た赤 |
|---|---|
| `--vvkb` を元の一行に戻す | `moved 7 time(s) ... (791 -> 764 -> ... -> 455)` と `starts at 791 and ends at 455 ... the frame the owner photographed with no row on it` |
| `vvTyping()` を外す | `welded to a keyboard that is not there` |
| `offsetTop` を引かない | `moved by 0 in the page instead of 40` |

戻したあと緑。

### 実機でないと分からないこと

- **iOS がアニメーションの間に `resize` を何回投げるか。** 測れません。
  **だから両方の場合で正しくなる形にしました** ── 一回でも二十回でも、
  二回目からは帯が一度も動きません。
- **一回目の開きが実際どう見えるか。** 最大しか採らないので下がることは
  ありませんが、上がる様子は実機でしか分かりません。
- **ハードウェアキーボード。** ソフトのキーボードを一度出したあと同じ起動で
  Bluetooth のキーボードに替えると、`vvKbMax` は大きいほうを覚えたままなので
  帯が浮きます。iPhone では稀ですが、**今日より悪くなる唯一の場合**なので
  書いておきます。潰すなら「欄に焦点があるのに一定時間キーボードが来ない
