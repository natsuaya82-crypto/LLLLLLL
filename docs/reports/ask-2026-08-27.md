## §3. 「日本語は1文字3バイト」の訂正 ── **9 です**

リーダーの指示にも前回の依頼にも「日本語は URL エンコードで1文字3バイト」と
ありますが、**3 は UTF-8 のバイト数**です。URL に入るのは
`encodeURIComponent` を通したあとで、**そこで3倍になります。**

```
あ  →  UTF-8 で E3 81 82（3バイト）  →  %E3%81%82（URL では 9 バイト）
```

実測（`node`、`encodeURIComponent(s).length`）:

```
a (ASCII) 1     space 3     = 3     / 3
あ 9     水 9     、9     ■ 9     ŋ 6     ʃ 6
```

**なぜ重要か:** 文字数で予算を組むと、日本語・韓国語・中国語で使っている人に
対してだけ**ちょうど3倍甘い**数になります。そしてその人たちは、**一番気づかれ
にくい人たち**です ── 日本語の入力欄が途中で切れていても、こちらには一件も
届きません（§4）。

**採った上限: 4000 バイト**（リーダーの数字）。RFC の 8000 より保守的で、
一次資料の床を下回りません。`ASK_MAX` は `www/assist.js` の一箇所です。

### 4000 バイトで実際に何語入るか ── **実装を動かして測りました**

辞書 510 語の言語で、`askLink()` が実際に組んだ URL:

| 画面の言語 | 意味の書かれ方 | URL バイト | 送られた単語 |
|---|---|---|---|
| en | English | 3989 / 4000 | **142 語** |
| en | 日本語 1字（水） | 3985 | **123 語** |
| en | 日本語 4字（大きい石） | 3999 | **67 語** |
| ja | English | 3998 | **107 語** |
| ja | 日本語 1字 | 3981 | **92 語** |
| ja | 日本語 4字 | 3981 | **51 語** |

**無料プランは 100 語なので、ほとんどの場合まるごと入ります。**
最悪（日本語UI・意味も日本語で長い）でも 51 語。

骨格だけ（単語ゼロ）は en 647 / ja 1420 バイト前後です。

## §4. 切れても分かりません ── だから送る前に測ります

**URL が長すぎても拒否されません。黙って切られます。**
短くなった本文が入力欄に出るだけで、エラーも警告も出ません。

そして `UIApplication.shared.open()` は**何も返しません** ── 戻り値も、
コールバックも、エラーも。universal link で外のアプリに渡した時点で、
**相手が何を受け取ったかはこちらから永久に見えません。**

だから `askLink()` は:

```
骨格すら入らない          → url を空で返す。開かない。行が「長すぎて送れません」になる
入る                      → 単語を予算いっぱいまで詰める
```

**切り詰めは一切しません。** 半分のプロンプトはこの仕組みが防ぐべき失敗そのもの
であって、生き延びる手段ではありません。

## §5. 実装 ── 一箇所と、その呼び出し口

### `www/assist.js`（追加）

| 名前 | 何か |
|---|---|
| `ASK_TO` | 相手と URL の**唯一の表**。`chatgpt` `gemini` `grok` `perplexity` |
| `ASK_MAX` | 4000（バイト） |
| `askBytes(s)` | `encodeURIComponent(s).length` |
| `askWho()` | `SET.askTo`。未設定・不明なら `chatgpt` |
| `askHead(extra)` | その言語の形。答えのない項目は**行ごと出しません**（空の「名前:」はバイトの無駄） |
| `askWords()` | 送る単語。**意味のない単語は送りません** ── 相手はそこから何も学べないので |
| **`askLink(ask, extra)`** | **本文をリンクにする一箇所。** 呼ぶ側は「何を出してほしいか」（`t()` を通した文）と自分の材料を渡すだけ |
| `askRow(ask, extra)` | 画面に置く一行 |

**`askLink` が「一箇所」です。** 宛先も、上限も、本文の組み立ても、他のどこも
知りません。二箇所目ができた瞬間に、片方だけ直る未来が確定します。

### `www/words.js`（1行 + コメント）

`wordsMore()`（辞書の ⋯ シート）の先頭に `askRow(t('ask.word.ask'), null)`。
**既存の行は1文字も動いていません** ── 新しい行が上に入り、
`border-bottom:none` の行は最後のままです。

### なぜ `<a>` で、`DO()` ではないか

1. **前例:** `www/settings.js:41,44` の利用規約リンクがこの形で出荷済み
2. **規則3に適う:** ボタンは**名前**を持ち、これは**行き先**を持つ
3. **`tools/press.mjs:400` が押さない:** あの walk は `[data-do]` を集めます。
   `DO('askWord')` にすると headless Chromium で `window.open` が走り、
   **ゲートの真ん中で新しいタブが生えます**
4. → **`act-map.js` の行が要りません**

⚠ **`location.href = url` は採りませんでした。** 実機では正しく動きますが
（`decidePolicyFor` → `.cancel`）、ブラウザでは本当にページが飛ぶので
`press` と `act` が壊れます。

### 外に本当に出るか ── **推測せず Swift を読みました**

`docs/keyboard-extension.md` の「Capacitor の呼び方を間違えて4回ビルドを溶かした」
を踏まないため、`node_modules/@capacitor/ios/Capacitor/Capacitor/WebViewDelegationHandler.swift`
を読みました:

- **111行** `decidePolicyFor` — 外部 URL の top-level navigation →
  `UIApplication.shared.open(navURL)` して `.cancel`
- **330行** `createWebViewWith` — `target="_blank"` / `window.open` →
  `UIApplication.shared.open(url)` して `nil`

`UIApplication.shared.open` に https を渡すのが **universal link が効く唯一の道**
です。**プラグインは要りません。**

## §7. 本文 ── **文面はオーナーのものです。確定していません**

### 7-a. なぜ10言語すべてなのか（見た目の話ではありません）

> **プロンプトの言語が、返ってくる答えの言語を決めます。**

英語だけで送ると、日本語で使っている人に**英語の単語**が返ります。それは
この機能が働いていないのと同じです。翻訳するのは**本文の枠だけ**で、
**材料（音・単語・語形）はその人が作ったものなので触りません。**

13鍵 × 10言語、入れました。`npm run i18n` 緑（10言語ぜんぶ、フォールバックゼロ）。

### 7-b. 材料に何を入れたか、と理由

| 入れた | 理由 |
|---|---|
| 言語の名前 | 呼び名がないと候補が「言語」の話にならない |
| 使う音 (IPA) | **これが無いと候補が英語の音で返ってきます。** 一番効く一行 |
| 文字数 | 「28文字しかない」が候補の長さを縛る |
| 語順 | 単語だけなら効きませんが、文法側が同じ関数を呼ぶときに要る |
| 音節数の最頻値 | 「10語中5語が1音節」── **形を真似させる唯一の材料**。`asWord()` が既に見ている数字と同じ |
| 品詞ごとの語末 | 「名詞は4語中2語が -r」 |
| すでにある単語 | 統計より効きます。**意味のないものは送りません** |

**入れなかったもの:** 辞書全体（§3 で入りません）· 文字の形（URL に載る大きさ
ではないし、相手は絵を受け取れません）· 使っていない音（候補作りの邪魔）

### 7-c. 実際に出た本文（en / 辞書10語）

```
I am building a constructed language in an app called Lingua.

Language name: Shango
Sounds (IPA): k t m n s r a i u e o
Letters: 39
Word order: SOV
Syllables: 1 in 5 of 10 words
Word ending: noun: -r in 2 of 4

Words it already has:
kano = mountain
tir = to see
mos = tall
sar = river
nak = not

Propose 8 new words that fit this language. Use only the sounds above, and
the word shapes it already has. For each, give the word, a meaning, its
reading in IPA, and one line on why that shape.
```

### 7-d. 同じもの（ja）

```
Lingua というアプリで人工言語を作っています。

言語の名前: Shango
使う音 (IPA): k t m n s r a i u e o

語末: 名詞は 4 語中 2 語が -r
```

### 7-e. 決めてほしいこと（4つ）

1. **本文の文面はこれでよいか。** 一語一句オーナーのものです。en / ja を直せば、
   残り8言語はこちらで合わせます
2. **候補は 8 つでよいか。** 「いくつか出せる」の「いくつか」
3. **上限 4000 バイトでよいか**（§3。無料100語がほぼ丸ごと入る数です）
4. **入口は辞書の ⋯ でよいか。** 単語を1つ選んでからではなく、辞書全体に対して
   「この言語に合う単語を出して」という形にしています
