## §2. 何文字入るか ── 測った結果と、測れなかったこと

### 2-a. まず、この容器では実測できませんでした

`chatgpt.com` に対して長さを変えた GET を投げて 414 が返る境界を測ろうとしま
したが、このセッションの egress プロキシが `chatgpt.com` を塞いでいます
（`curl: (56) CONNECT tunnel failed, response 403`、8 段階すべて）。
**「ChatGPT が実際に何バイトで切るか」は実測されていません。** 下の数字は
仕様と公開情報からの上限であって、ChatGPT の実装の数字ではありません。
**これは実機（か、外に出られる環境）でしか埋まりません。** §7 に名指しで
書いてあります。

### 2-b. 出典のある数字

| 何の上限か | 数 | 出典 | 一次資料か |
|---|---|---|---|
| HTTP の request-line として、**送り手も受け手も最低これだけは通すべき** | **8000 octets** | RFC 9112 §3 "It is RECOMMENDED that all HTTP senders and recipients support, at a minimum, request-line lengths of 8000 octets." https://datatracker.ietf.org/doc/html/rfc9112 | ○ 仕様 |
| Cloudflare が 414 を返す URI 長（`chatgpt.com` は Cloudflare の後ろ） | 16KB〜32KB（資料が割れる） | https://developers.cloudflare.com/support/troubleshooting/http-status-codes/4xx-client-error/error-414 · https://community.cloudflare.com/t/loadbalancing-url-length-16k-vs-32k/379870 | △ ベンダ文書。**直接開けず**、検索インデックス経由 |
| Safari（macOS/iOS）の URL 長 | 約 80,000 文字 | https://www.sistrix.com/ask-sistrix/technical-seo/site-structure/url-length-how-long-can-a-url-be | ✕ 二次資料。**直接開けず**（egress ブロック） |
| iOS の universal link の長さ上限 | **文書化されていない** | https://developer.apple.com/forums/thread/68429 — Apple 自身のフォーラムで同じ質問が出て、**返信ゼロ**のまま | ○ 無いことの出典 |
| `chatgpt.com/?q=` の長さ上限 | **文書化されていない** | OpenAI に公開文書なし。`?q=` を使う既存プロジェクトも上限を書いていない https://github.com/combinatrix-ai/prompt-chatgpt-via-url-parameter · https://community.openai.com/t/query-parameters-in-chatgpt/1027747 | ○ 無いことの出典 |

**読み方:** 一次資料として使える数は **8000 octets（RFC 9112）だけ**です。
80,000 も 16KB も、この機能が壊れるかどうかを決める場所ではありません。
決める場所は ChatGPT 自身で、そこには公開された数字がありません。

### 2-c. 依頼文の「日本語は1文字3バイト」を訂正します

3 バイトは **UTF-8 のバイト数**です。URL に入るのは
`encodeURIComponent` を通したあとで、**そこで 3 倍になります**
（あ → `%E3%81%82` → **9 文字 = 9 バイト**）。実測（`node`、
`encodeURIComponent(s).length`）:

```
a (ASCII)   -> 1        あ (かな)   -> 9
0 (ASCII)   -> 1        水 (漢字)   -> 9
space       -> 3        、(句読点)  -> 9
newline     -> 3        ■           -> 9
=           -> 3        ŋ ʃ (IPA)   -> 6
```

**日本語は1文字 9 バイト、IPA 記号は 6 バイト。** 予算はこれで割ります。

### 2-d. 実際の本文で測った

§4 の本文案をそのまま `encodeURIComponent` に通した数（`https://chatgpt.com/?q=`
の 23 バイト込み）:

```
骨格（単語ゼロ）   JA 1724 バイト  /  EN  647 バイト
単語 1 行あたり    JA "kama = 水"          25 バイト
                   JA "tesira = 大きい石"  54 バイト
                   EN "kama = water"       21 バイト
```

予算に入る単語の行数:

| 予算 | JA（意味が短い） | JA（意味が長い） | EN |
|---|---|---|---|
| 2000 バイト | **10 語** | **4 語** | 63 語 |
| **8000 バイト** | **250 語** | **115 語** | 349 語 |
| 16000 バイト | 570 語 | 263 語 | 730 語 |

辞書を丸ごと載せた場合（参考、JA・意味が短い）:

```
 100 語 →   4,247 バイト
 500 語 →  14,247 バイト
5000 語 → 126,747 バイト
```

### 2-e. 提案する予算 ── **8000 バイト**、ただし決めるのはオーナーです

**8000 を薦める理由:**

1. **一次資料のある唯一の数**で、しかもバイトで書かれている（RFC 9112 §3）。
   ここより下なら「通らない実装がある」とは誰も言えません。
2. **無料プランの辞書は上限 100 語**で、それを丸ごと載せても **4,247 バイト**。
   8000 なら無料プランの人は**辞書全部**を送れます。
3. 500 語で 14,247 バイトなので、**有料プランは必ず間引く**ことになります ──
   依頼文の「辞書を丸ごと載せない」がここで数字になります。
4. 下限側の目安としてよく言われる 2000 バイトは、**日本語では使えません**:
   骨格だけで 1724 バイト、残りに 10 語しか入りません。

**2000 は却下、16000 以上は根拠なし**、というのがこちらの読みです。
**8000 で進めてよいか、一行ください。**

### 2-f. 切れたときアプリから分かるか ── **分かりません**

`<a href target="_blank">` も `UIApplication.shared.open()` も、
**開いた先が何を受け取ったかを返しません。** 戻り値も、コールバックも、
エラーもありません。ChatGPT が URL を切っても、切ったことは
**この app には一生届きません。**

だから依頼文の指示どおり、**送る前にこちら側で測る**しかありません:

```
長い版が予算に入る            → 長い版で開く
入らない                      → 短い版に落とす（落としたことは「状態」として出す）
短い版も入らない              → 開かない。「入りきらない」と言う
```

## §3. 外に本当に出るか ── Capacitor 側は読んで確かめました

`docs/keyboard-extension.md` の「Capacitor の呼び方を間違えて4回ビルドを溶かした」
を踏まないために、**推測せず `node_modules/@capacitor/ios` の Swift を読みました。**

`node_modules/@capacitor/ios/Capacitor/Capacitor/WebViewDelegationHandler.swift`:

- **`decidePolicyFor` (67行)** — top-level の navigation で、行き先が
  `serverURL`/`localURL` で始まらない場合 → `UIApplication.shared.open(navURL)`
  して `decisionHandler(.cancel)`（111行）。web view は動かず、OS が開く。
- **`createWebViewWith` (328行)** — `target="_blank"` / `window.open` が来た場合
  → `UIApplication.shared.open(url)` して `nil` を返す（330行）。

`UIApplication.shared.open` に https の URL を渡すのが、**universal link が
効く唯一の道**です。ChatGPT アプリが入っていればアプリ、無ければ Safari。
**プラグインは要りません。** `LinguaShare` のような自前ブリッジも不要です。

**採る形: `<a href="…" target="_blank" rel="noopener">`。** 理由は3つ:

1. **前例がある。** `www/settings.js:41,44` の利用規約・プライバシーが
   まさにこの形で、既に出荷されています。
2. **規則3に適う。** `on*=` を書かず、コードも持ちません（名前ではなく行き先
   を持つ、`settings.js` と同じ）。
3. **`press.mjs` が押しません。** `tools/press.mjs:400` は
   `[data-do]` だけを集めます。`DO('askWord')` にすると headless Chromium で
   `window.open` が走り、ゲートに新しいタブが生えます。`<a>` ならそれが無い。

⚠ **`location.href = url` は採りません。** 実機では正しく動きますが
（`decidePolicyFor` → `.cancel`）、ブラウザでは本当にページが飛ぶので
`press`/`act` が壊れます。

**実機で確かめるべきこと（§7）:** 設定画面の利用規約リンクが実機で外に開いて
いるなら、これは同じ道です。**開いていないなら、この設計ごと作り直しです。**

## §4. 本文の案 ── **決めるのはオーナーです**

依頼文どおり、**文面は確定させていません。** 下は案で、`docs/FEATURES.md` にも
`SPEC` ではなく `OWNER DECISION 待ち` として置きます。

### 4-a. 何を材料に入れたか、と理由

| 入れる | 理由 |
|---|---|
| 言語の名前 | 呼び名がないと候補が「言語」の話にならない |
| 使う音（IPA、`addedSnd()`） | **これが無いと候補が英語の音で返ってきます。** 一番効く一行 |
| 文字数（`LETTERS.length`） | 「28文字しかない」が候補の長さを縛る |
| 語順（`STG.order`、既定 SOV） | 単語だけなら効きませんが、文法ページから同じ関数を呼ぶときに要る |
| 音節数の最頻値（`analyze().sylMode`） | 「2音節が40語中26語」— **形を真似させる唯一の材料**。`asWord()` が既に見ているのと同じ数字 |
| 語末の規則（`analyze().finalRule`） | 「名詞は -a で終わりやすい 12/18」— 品詞ごとの形 |
| **既にある単語を何語か** | 統計より効きます。ただし §2-d のとおり**丸ごとは入りません** |

**入れないもの、と理由:**

- **辞書全体** — 500 語で 14,247 バイト。予算超過（§2-d）
- **文字の形（ストローク）** — URL に載る大きさではないし、ChatGPT は絵を
  受け取れません
- **`SND` の未使用音** — 「使っていない音」は候補作りの邪魔にしかなりません

### 4-b. 案（日本語）

```
私は Lingua というアプリで人工言語を作っています。
この言語に合う新しい単語の候補をいくつか出してください。

言語の名前: {0}
使う音 (IPA): {1}
文字数: {2}
語順: {3}
音節数: {4} が最も多い ({5} 語中 {6} 語)
語末: {7} は -{8} になりやすい ({9} 語中 {10} 語)

すでにある単語:
{11}

上の音と語の形だけを使ってください。
それぞれ読み (IPA) と、なぜその形にしたかを一行で書いてください。
```

```

Language name: {0}
```

### 4-d. 決めてほしいこと（4つ）

1. **本文はこれでよいか。** 一語一句オーナーのものです
2. **候補は 8 つでよいか。** 「いくつか出せる」の「いくつか」の数
3. **本文は `t()` を通すか。** ── **通すべきだと考えます。**
   日本語で app を使っている人が英語のプロンプトを送るのは変です。ただし
   **10言語ぶんの本文をオーナーが決める**ことになります。

   ── これは `i18n-check` が落ちます（フォールバック1件で赤）。
   **通すなら10言語ぶん要ります。** ここは判断です
4. **予算 8000 バイトでよいか**（§2-e）
