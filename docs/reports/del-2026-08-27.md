## 4. ⚠ ここで止めています ── `SLICES` の件

`CLAUDE.md` 規則6:「being *in* it is what makes a slice real」。
`SLICES` に入れると **`wipeAll` が消し**（オーナーの決定どおり）、
**同時に `bkPack()` が拾います**（バックアップに入り、書きかけも戻る）。
**オーナーはバックアップ側について何も言っていません。**

### 4-1. そもそも `SLICES` には入れられません ── これは判断ではなく事実です

`SLICES` は**言語のスライス**の一覧で、`bkPack()` も `wipeHere()` も
**`langKey(slice)`**（＝ `lingua.<言語id>.<slice>`）として読み書きします。

```
www/settings.js:403   localStorage.removeItem(langKey(SLICES[si]));
www/backup.js:89-90   for(...) k=SLICES[i];        ← langKey(k) として読む
```

下書きの鍵は `lingua.drafts` で、**`lingua.<id>.drafts` ではありません。**
`SLICES` に `'drafts'` を足すと、消えるのも拾われるのも
**`lingua.<id>.drafts` という存在しない鍵**になり、本物の `lingua.drafts` は
**残ったままになります。**気づかれません ── 何も投げないからです。

**なので選択肢は二つで、どちらも「判断」です:**

| | やること | 削除 | バックアップ |
|---|---|---|---|
| **A** | `wipeHere()` に `removeItem(LS_DRAFTS)` を一行 | ○ | 入らない（今と同じ） |
| **B** | 下書きを `langKey('drafts')` に移す＋`SLICES` に足す | ○ | **入る** |

**A は決定そのままです。**オーナーが言ったのは「消える」だけで、
バックアップの話はしていません。一行で、形も場所も変えません。

**B は決定を超えます。**下書きを「言語のもの」に作り替えることになり、
バックアップに入り、**移行が要ります**（既にある `lingua.drafts` を
どの言語の下へ移すのか ── §4-2）。

**私は A を書くつもりですが、書いていません。**B にすべきかはオーナーの
ものだと思うので、投げます。

### 4-2. B を選ぶなら、先に答えが要る問い

**下書きは、どの言語で書いたかを持っていません。**
`draftKeep()` が積むのは `{at, ln, mn, to, pr, pics, vo, pv}` だけで、
言語 id はどこにもありません。

- 既にある下書きを `langKey('drafts')` に移すなら、**どの言語の下に置くのか。**
  今開いている言語、は「そこで書かれた」という意味にはなりません。
- 「言語を消したらその言語の下書きも消える」を**厳密に**やるには、
  新しい下書きに言語 id を載せる必要があります ── それは
  **保存されるものを増やす**話で、決定には含まれていません。

**A ならこの問いは立ちません。**下書きは端末のもののままで、
`wipeAll` は端末ごと消す唯一の操作だからです。
