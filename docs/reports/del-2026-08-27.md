---

## 1. 何が起きていたか ── 七件ではなく、一つの原因でした

`wipeAll()` は `SLICES` を回して `langKey(SLICES[i])` を消していました。
`SLICES` は**言語の作り**なので、それ以外の鍵は一本も入っていません。
`removeItem` はアプリ全体で**二箇所**しかありませんでした。

```
lingua.drafts   下書き              残っていた
lingua.posts    投稿の写し          残っていた
lingua.me       名前・顔・自己紹介   残っていた
lingua.langs    言語の索引          残っていた
lingua.cur      開いている言語       残っていた
lingua.words ほか旧8本              残っていた
lingua.set      設定                既定値で上書きされるだけ
```

**一行足すのは直し方ではありませんでした。**次に鍵を足した日に、また同じことが
起きます。

## 2. 直したところ

| file | 何を |
|---|---|
| `www/core.js` | `lsWipeNS()` ── `localStorage` を数え上げて `lingua.` の鍵を全部消す。**一覧は無い** |
| `www/settings.js` | `wipeHere()` がそれを呼ぶ。そのあと `langFirst()` で**新しい id**。theme/ui/plan も持ち越さない |
| `ios/App/App/LinguaShare.swift` | `dropAll` ── Documents の三つのフォルダを空にする |
| `www/backup.js` | `bkDropAll()` が `dropKept` ではなく `dropAll` を呼ぶ |
| `tools/backup-check.mjs` | 主張を四つ、両方向で |
| `CLAUDE.md` | 規則6 の「`wipeAll` walks it」を直した（古い文は削除） |

### 接頭辞は点まで

`'lingua.'` を `indexOf(...)===0` で見ます。**`lingua` という鍵や `linguaX...` は
他人のもので、触りません。**検査がその二本を置いて、残ることを見ています。

### `langFirst()` で新しい id にした理由

古い id のままだと、`wipeHere()` の後半の `save()` `saveLetters()` などが
**古い言語の鍵を書き戻していました**（`ltStart()` が28文字を作り直すので）。
新しい id を作れば、消した言語の鍵は一本も戻りません。これは一回目の実装で
実際に赤になって分かりました。

### 設定について

`theme` `ui` `plan` を持ち越しません。**プランは次の起動で Keychain から
戻ります** ── アカウントを消すことは購読の解約ではなく、Apple には何も
言っていないからです。`npm run plan` は緑で、money が何を守るかは変わって
いません（消えるものはプランに関係なく全部消えます）。

## 3. Documents ── 口が二つ足りませんでした

```
Documents/Languages/   dropKept があった（世代 .1 .2 込みで消す）
Documents/Voices/      dropVoice(name) で一本ずつ。一括は無かった
Documents/Sheets/      消す口が無かった
```

**在ることにしないために書きます** ── 無かったので `dropAll` を足しました。
`dropKept` と同じ形（同じ error 処理、同じ `["gone": n]`）で、**三つの
フォルダの中身だけ**を消します。`Documents` そのものは人のフォルダで、
Files アプリから置いたものがあり得るので触りません。

## 4. 言語を一つ消すほう ── **ボタンが存在しません**

`vLangs()`（`www/home.js:1504`）は並べて足すだけで、**消す道がどこにもありません。**
`langWipe()` を書きましたが `dead-check` が赤にしたので外しました ──
誰も呼ばない関数だからです（`CLAUDE.md`「we'll need this later」は禁止）。

**「言語を消すでも言語系は全部消す」は、消す操作が作られた日に効く仕様です。**
`core.js` のコメントに、そのとき何を歩くか（`langKeyOf()` で一つの id の
`SLICES`、`lsWipeNS()` ではない）を書いて残しました。**作るのは別の仕事で、
それ自体に DELETE REVIEW が要ります。**

### リーダーへ、一行

**「アカウント削除のあと `lingua.` の鍵が一本も無い」は、`lsWipeNS()` が
返った瞬間については成り立ちますが、`wipeAll()` が返った時点では成り立ちません** ──
そのあとアプリが**まっさらな初回起動の状態**を書くからです（`langFirst()` が
`lingua.langs` と `lingua.cur` を、`ltStart()` が新しい言語の28文字を）。
それは人のデータではなく、**新品の端末と同じ状態**です。
なので検査は「**消えた言語の id を含む鍵が一本も無い**」＋「下書き・名前・投稿が
読めない」で聞いています。**そこだけ literal から外しました。**
literal のほうが良ければ言ってください ── その場合は初回起動の状態を書かずに
返すことになり、次の起動まで言語が無い端末になります。
