# 品詞をもっと細かく ── 今どうなっているかと、細かくするなら三つの形

**調べて案を出しただけです。一行も実装していません。**決めるのはオーナーです。

枝 `claude/words`。

> 「品詞もさ、女性名詞とか細かく分けたい人いるでしょ多分、もっと細かく選択肢
> 分けれないの？」OWNER 2026-09-05（実機）

---

## 先に一つ、大事なこと

**「女性名詞」は品詞ではありません。**「名詞」が品詞で、「女性」は**その名詞が
どの組に属するか**です。世界の言語では、この二つは別の軸として扱われています ──
だから「品詞の一覧をただ長くする」やり方では、この言葉には届きません。

- **軸①：品詞**（名詞・動詞・形容詞…）── 今アプリにあるもの。
- **軸②：その品詞の中の分かれ方**（性、数、格、活用の型…）── **今アプリに
  ありません。**「女性名詞」はここです。

案は三つ出します。**①だけ増やす案**、**②を足す案**、**②を足したうえで
その言語自身の言葉も使える案**です。

---

## 一 ── 今、何が選べるか

**品詞は 13 個**です。`POS`（`www/shell.js`）にキーで並んでいて、画面に出る
言葉は 10 言語ぶんの表から引いています（`LANG[L].pos`）。**保存されるのはキー
だけ**なので、表示言語を変えても既に書いた辞書は動きません。

| | | |
|---|---|---|
| `n` 名詞 | `v` 動詞 | `adj` 形容詞 |
| `adv` 副詞 | `pro` 代名詞 | `num` 数詞 |
| `part` 助詞 | `conj` 接続詞 | `intj` 感動詞 |
| `aff` 接辞 | `nm` 固有名詞 | `idm` イディオム |
| `x` その他 | | |

**品詞のほかに、単語が既に持っているもの。**

| 何 | いくつ | どこ |
|---|---|---|
| **文体**（`reg`） | 5（空・話し言葉・書き言葉・俗・丁寧） | `www/wordsheet.js` |
| **活用・派生の名前**（`fm`） | 活用 12・派生 12、**＋自分で足したもの** | 同上 |
| **分野**（`tags`） | 自由に書ける | 同上 |

**`fm` は既に「こちらが用意した並び ＋ その言語が自分で足した言葉」の形です。**
自分で足したものは `i~` `d~` を頭につけて**単語そのものに**保存され、翻訳され
ません（その言語の言葉だから）。案三はこの形を借ります。

**品詞のキーを読んでいる場所（増やすと触る所）。**

- 単語の一覧の絞り込みと並び順（`www/words.js`）
- 単語のシートと品詞を選ぶ画面（`www/wordsheet.js`）
- 取り込み ── CSV の「品詞」欄を読む（`posKey()`、`www/import.js`）
- カード（`www/card.js`）、統計（`www/core.js`）
- **文法の章と段**（`www/grammar.js` `www/phases.js`）── 段は品詞ごとに立って
  います（名詞の段、動詞の段…）
- **文法エンジンの対応表**（`www/grammar-engine/adapter.js`）

**エンジンは既に `ADPOSITION` を知っています。**アプリ側にキーがないだけです。

## 二 ── 世界の言語がどう分けているか

**軸①（品詞）で、アプリに無いもの。**Universal Dependencies が使う 17 種と
比べると、足りないのは四つです。

| 足りないもの | 例 |
|---|---|
| **接置詞**（前置詞・後置詞） | 英 *in*、日「に」「へ」 |
| **助動詞** | 英 *be, have, will*、日「れる」「せる」 |
| **限定詞・冠詞** | 英 *the, a, this*、仏 *le, une* |
| **接続詞を二つに** | 等位（*and*）と従属（*because*）は働きが違う |

**軸②（その品詞の中の分かれ方）。**「女性名詞」はここです。世界でよく使われて
いるのは次の五つで、**どれも「持たない言語」がふつうにあります。**

| 軸 | どう分かれるか | 例 |
|---|---|---|
| **性・名詞クラス** | 2（男・女）／3（男・女・中）／通性と中性／有生と無生／それ以上 | 仏 2、独 3、露 3、スワヒリ語はふつう 15〜18 に数える。日本語・トルコ語・フィンランド語・韓国語は**持たない** |
| **数** | 単・複／＋双数／＋少数 | アラビア語とスロベニア語に**双数**がある |
| **格** | 無し／4〜6／十数個 | 独 4、露 6、ラテン語 6、フィンランド語はよく 15 と数える |
| **活用・曲用の型** | その言語が持つ型 | ラテン語は曲用 5・活用 4、日本語は五段・上一段・下一段・カ変・サ変、スペイン語は -ar/-er/-ir |
| **自動詞・他動詞** | 2（＋両方） | ほぼどの言語にもある区別 |

**ここから分かること。**「女性名詞」を選べるようにするというのは、**名詞の下に
一段作る**ということです。そしてその一段の中身は言語ごとに違います ── 三つで
足りる言語も、十五要る言語も、一つも要らない言語もあります。

## 三 ── 案（どれか一つ、または組み合わせ）

### 案 A ── 品詞そのものを増やす（一段のまま）

上の四つを足して **13 → 17**。接置詞・助動詞・限定詞を足し、接続詞を等位と
従属に分けます。

- **できるようになること。**文法の段が接置詞や助動詞を持てます。取り込みで
  *preposition* と書かれた列がその通りに入ります。
- **「女性名詞」には届きません。**軸②に何も足さないからです。
- **触る所。**`POS`・10 言語の表（4 個 × 10 ＝ 40 行）・`posKey()` の別名・
  エンジンの対応表・**文法の段**（新しい品詞の段を立てるか、立てないかの判断が
  要ります）。
- **保存されるものの変化。****既にある単語は一つも動きません。**キーが増える
  だけです。
- **一覧が 17 行になります。**横に並べるのは禁止なので、これは**四件目の蛇腹**が
  要る理由でもあります。

### 案 B ── 二段にする（品詞 ＞ その中の分かれ方）

**品詞の 13 個はそのまま**にして、その下に**任意の**二段目を足します。

```
名詞  >   （開くと）  男性 / 女性 / 中性 / 通性 / 有生 / 無生
動詞  >   （開くと）  自動詞 / 他動詞
```

- **できるようになること。**「女性名詞」がそのまま選べます。一覧の行は
  「名詞・女性」と出ます。
- **任意です。**二段目を選ばない単語は今までどおり「名詞」だけ。**性の無い言語を
  作っている人には何も増えません。**
- **保存。**単語に**もう一つ欄が増えます**（例：`pos2`）。**`pos` は一切
  触りません** ── だから文法の段もエンジンも取り込みも今のままで動きます。
  既にある単語は二段目が空です。
- **触る所。**単語のシート、品詞を選ぶ画面、一覧の行と絞り込み、10 言語の表
  （二段目のぶん）。**文法側は触りません。**
- **オーナーが決めること。**どの品詞に二段目を付けるか。中身をいくつにするか。
  **一覧の行に出すかどうか。**絞り込みの対象にするかどうか。

### 案 C ── 案 B ＋ その言語自身の言葉で足せる

案 B に、**「自分で書く」を一つ足します。**用意した並びの下に空の欄があり、
そこに書いた言葉がその単語に保存されます ── **翻訳されません。**その言語の
言葉だからです。二回目からは、**その言語が既に使っている言葉が並びに出ます。**

- **なぜこれがあるか。**性は言語ごとに数が違います。三つで足りる言語も、
  スワヒリ語のように十五要る言語もあり、**作っている言語が何を持つかは
  こちらには分かりません。**
- **これは新しい仕組みではありません。**活用・派生の名前（`fm`）が既にこの形で、
  自分で足したものを `i~` `d~` を頭につけて単語に保存し、`fmMine()` が
  「この言語が既に使っている言葉」を単語から読み直しています。**同じ形を
  借りるだけです。**
- **触る所。**案 B ＋ 欄一つ ＋ 読み直す関数一つ（別の名前で既にあるもの）。
- **オーナーが決めること。**案 B のぜんぶ ＋ 自分で書けるのをどの品詞に許すか。

## 四 ── 三つを並べて

| | 「女性名詞」に届く | 既にある単語 | 文法の段 | 10 言語の表 | 保存が増える |
|---|---|---|---|---|---|
| **A** 品詞を 17 に | **届かない** | 動かない | **触る** | ＋40 行 | 増えない |
| **B** 二段にする | **届く** | 動かない（二段目が空） | 触らない | 二段目のぶん | **欄一つ** |
| **C** B ＋ 自分で書ける | **届く。数の制限なし** | 動かない | 触らない | 二段目のぶん | **欄一つ** |

**A と B は排他ではありません。**両方やることもできます（品詞を 17 にして、
そのうえで名詞に性を付ける）。

**四件目（蛇腹）との関係 ── 入れ物だけ先に作ることはできません。**

「名詞 ＞」と開く形は、**A なら 17 行を畳むため**のもの、**B・C なら二段目
そのもの**になります。**どちらにしても、開いた先に何が入るかは上の決定です。**

そして**このアプリの蛇腹は、開く先が空の見出しを作りません。**記事の蛇腹
（`abHead()`、`www/home.js`）にはかつて「開く先が無い見出し」があり、印の無い
ただの行として描かれていました（`.abshp`）。**それは消されていて**、読む側は
中身の無い節を蛇腹に渡す前に落とします ── `press` がそのクラスをどの画面でも
誰も着ていないと数えたのが、消えたことの証拠です。

**今の品詞 13 個は、一つ残らず開く先がありません。**今のまま蛇腹にすると、
**開いても何も出ない見出しが 13 個**並びます。それはこのアプリが一度捨てた形
です。

**なので四件目は、三件目の答えを待ちます。**答えが出た日に、`ABOPEN` と
`abHead()` と同じ形で作ります ── 新しい仕組みは作りません。
