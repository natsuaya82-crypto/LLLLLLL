## 違う ── ⑭ 320pt で「4.99/月」が一列になっていない

オーナー: 「プランのボタンは枠で囲え。**4.99/月は一列**」

**測りました**（`.pp` と `.pper` の矩形が同じ行に重なるか）:

| 画面 | `$4.99 ／月` | `$49.99 ／年` |
|---|---|---|
| 390×844 | 同じ行 ✓ | 同じ行 ✓ |
| 375×667 | 同じ行 ✓ | 同じ行 ✓ |
| **320×568** | **折り返す ✗** | **折り返す ✗** |

### 原因: `.btn.plterm` の `padding` が二回書かれていて、後が勝っている

```
www/index.html:1483   .btn.plterm{padding:10px 8px}
www/index.html:1503   .btn.plterm{border:1px solid var(--line);border-radius:12px;padding:10px 12px}
```

同じ強さで 1503 が後なので **`10px 12px` が勝ちます**。実測でも
`padding: "10px 12px"`。**1483 行は死んでいます。**

1483 は「320 で値段が割れる」を直すために入れられた行です
（`74e42a2`「プランの値段が一列に入る ── 私が入れた枠が壊していた」）。
**その直しは、同じファイルの20行下にある枠の規則に打ち消されています。**

### ただし padding だけでは足りません

`padding:10px 8px` をブラウザで生かして測り直すと:

- `$4.99 ／月` → **同じ行になる**（直る）
- `$49.99 ／年` → **まだ折り返す**（直らない）

**320 では枠の中に年額が入りません。** 枠（`border` + `border-radius:12px` +
padding）と 1.1rem の数字と `／年` が、102px の中で両立していません。
`.plterm .pp` は 1474 で 1.25rem、1484 で 1.1rem に上書きされていて、こちらは
効いています（後勝ちが意図どおりに働いている側）。

**私は直しません** ── `www/index.html` はリーダーのものです。どう詰めるか
（padding を一本にする／320 で数字をもう一段落とす／`／年` を隠す）は
持ち主の判断です。
