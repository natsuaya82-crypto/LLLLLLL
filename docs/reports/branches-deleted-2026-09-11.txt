理由（一つだけ）
  git push origin --delete <branch> が、このセッションの権限分類で拒まれた。
  proxy の 403 ではない。返ってきたのはこれ:

    Permission for this action was denied by the Claude Code auto mode
    classifier. Reason: [Git Destructive].

  試したのは claude/aud-claude 一本。リーダーのセッションで 403 だったものが、
  ここでは 403 まで届かず手前で止まる。道は二つとも塞がっている。
  force-push も空 commit も試していない（禁止）。

  次に必要なのは、削除を許す設定か、削除できる人の手。
  このセッションからは一本も消せない。

確かめたこと（消せてはいないが、一覧は正しい）
  1. .git/shallow があった。このクローンは浅く、origin/master は 92 commit しか
     持っていなかった。その状態で git branch -r --merged origin/master に訊くと
     111 本のうち 96 本が「取り込まれていない」と答える ── 嘘である。
     git fetch --unshallow のあと master は 2937 commit になり、
     111 本すべてが --merged に出た。

     **浅いクローンで --merged を訊いてはいけない。**「取り込まれていない」と
     いう答えが返り、それを信じると、消して良いものを消さずに終わるか、
     もっと悪い向きに間違える。深さを取ってから訊く。

  2. 深さを取ったあとの答え:
       origin/master に取り込まれている remote ブランチ   215 本
       うち一覧の 111 本                                  111 本すべて一致
       一覧にあって取り込まれていないもの                 0 本
     一覧は 2026-09-09 の時点でも今日の master でも正しい。111 本は消して良い。

  3. claude/gatered は一覧に無い。
     指示は「まず claude/gatered を試せ」だったが、同じ指示に
     「一覧に無いものは消さない」とある。一覧の中の claude/aud-claude で試した。
     gatered 自体は remote にあり master に取り込まれている（215 本のうちの一本）
     が、111 本の一覧には入っていないので、消して良いかはオーナーのもの。

  4. 一覧の外にも、master に取り込まれている remote ブランチが 104 本ある
     （215 − 111。master 自身を除く）。2026-09-09 以降に取り込まれた分。
     これも消して良いかは確かめ直していない ── 一覧の仕事ではない。
