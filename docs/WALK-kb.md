再現手順（#1）:
1. `SET.plan='pro'`。プロフィール → 言語 → ＋ で言語を新しく作る（有料で作った
   言語なので、無料の 38 スロットは一度も作られていない）。
2. 制作タブ → 探す → 「一覧を取り込む」。次の二行を貼る（区切りはタブ）:
   `char⇥name` / `Ω⇥q` / `Ψ⇥z`。
3. 「文字に入れる」を選んで［取り込む］。`LETTERS` は 2 つ、どちらも
   `nm`（名前）だけを持ち `ab` は空。
4. プランが無料に落ちる。次の起動で `ltStart()` が走る。
5. 文字 → アルファベットを開く。24 文字。q と z が無い。「2 hidden」と出る。

何が起きているか（読んで確かめたのではなく、押して数えた）: 「このスロットは
もうあるか」を `ltStart()` は **名前**（`ltName`、`nm` → `ab` → 音の順に見る）で
訊き、「これは 38 スロットの一つか」を `ltIsBase()` は **`ab` だけ**で訊く。
取り込みが作る文字は `nm` を持ち `ab` を持たないので、前者には「ある」と答え、
後者には「無い」と答える。だから q のスロットは作られず、q と名乗る文字は
無料では隠れる。無料の QWERTY は名前でキーを探す（`kbNamed('q')`）ので、
q のキーは隠れている文字を指している。

## 正しく動いたことの記録

### 文字を描く
- **描く**。線を引くと［保存］が灰（`rgb(142,136,124)`）から金
  （`rgb(138,106,34)`）に変わる。
- **取り消し・やり直し・全消し**。二本引いて取り消し二回で 0 本、やり直し二回で
  2 本、全消しで 0 本、そのあと取り消しで 2 本が戻る。全部正しい。
- **ラウンド**。一回押すと `on`、もう一回で `off` に戻る。
- **塗り**。`fill:true` が付いた線が保存され、開き直しても残る。
- **保存して開き直す**。線を引いて［保存］→ `ltById('lt.a').st` に 1 本入り、
  `SET.myfont` が true になり、一覧へ戻って開き直しても残っている。網が無いので
  画面はその場に留まり、［保存］は金のまま（2026-09-05 の決定どおり）。
- **描きかけでタブに出て戻る**。線を引いた状態で下のタブでフィードへ出て、制作
  タブから文字→その文字→編集と入り直すと、引いた線がそのまま残っている。
- **保存せず戻る**。戻る矢印で「Save what you have typed?（はい／いいえ）」。
- **ペンの太さは無い**。`www/glyph.js` の頭に「One pen, everywhere」。仕様。

### 文字の音
- 音の表は文字のページの［音］から開く。押すと付き、同じものをもう一度押すと
  外れる（`["a"]` → `["a","k"]` → `["a"]`）。別のものを押すと入れ替わる。
- **無料では表のどのマスを押してもアップグレードのポップ**。画面の形は有料と
  同じで、押したら有料へ飛ぶ ── 2026-09-04 の決定どおり。

### 書記体系
- 無料は五種類のどれを押してもアップグレードのポップが出て、`wsys()` は
  `alpha` のまま。
- Pro では選んだだけでは変わらず、［保存］で `wsys()` が変わる。

### 無料の QWERTY
- 五行とも合計 10（10 / 10 / 0.5+9+0.5 / 7+削除3 / 1+1+スペース6+改行2）。
- 文字が見つからない位置はローマ字のキーが残り、行が短くならない。

### キーボードの編集（Pro）
- 五つの並び（QWERTY・フリック・タップ・チャート・ABC）が全部作れて、どれも
  全行が合計 10。
- **上限**。Plus は板 0 を入れて 4 枚目の＋で止まる。Pro は止まらない。
- **行を消す**。番号を押して選び、ゴミ箱でその行だけが消える。取り消しで戻り、
  やり直しでまた消える。
- **列を消す**。列の文字を押して選び、ゴミ箱で全行から一キー分ずつ。QWERTY の
  半キー分ずれた三行目は、跨いでいる二つのキーが半分ずつ細くなる（消えない）。
  取り消しで完全に戻る。
- **列の選択が光る範囲**。三行目（半キーで挿し込んである行）はどの列を選んでも
  一つも光らない。仕様どおり。
- **寄せ**。三キー分短い行で 左＝`gap:3` が右端、中央＝`gap:1.5` が両端、
  右＝`gap:3` が左端。半キー分ずれた行でも同じように割れる。
- **結合**。キーを二つ選ぶと結合ボタンが上がる。横並びなら幅が足されて一つに
  （行の合計は 10 のまま）、縦なら上のキーに `h:2`、下の行に `up` を持つ隙間。
  どちらも取り消しで完全に戻る。**一つだけ選んでいる間は結合ボタンは出ない**。
- **面（レイヤー）**。＋で面が増え、増えた面には行き来のキーが一つずつ最初から
  乗っている（面 0 に「1 へ」、面 1 に「0 へ」）。
- **ボタンが下りている**。何も選んでいないときは取り消し・やり直し・寄せ三つ・
  ＋・ゴミ箱が全部下りている。行が五段まで埋まっている QWERTY では、行を選んでも
  ＋は下りたまま（`kbRowsMax()` は 5）。
