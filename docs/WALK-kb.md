再現手順（#1）:
1. `SET.plan='pro'`。プロフィール → 言語 → ＋ で言語を新しく作る（有料で作った
   言語なので、無料の 38 スロットは一度も作られていない）。
2. 制作タブ → 探す → 「一覧を取り込む」。次の二行を貼る（区切りはタブ）:
   `char⇥name` / `Ω⇥q` / `Ψ⇥z`。
3. 「文字に入れる」を選んで［取り込む］。`LETTERS` は 2 つ、どちらも
   `nm`（名前）だけを持ち `ab` は空。
4. プランが無料に落ちる。次の起動で `ltStart()` が走る。
5. 文字 → アルファベットを開く。24 文字。q と z が無い。「2 hidden」と出る。

何が起きているか（読んで確かめたのではなく、押して数えた）: 「このスロットは
もうあるか」を `ltStart()` は **名前**（`ltName`、`nm` → `ab` → 音の順に見る）で
訊き、「これは 38 スロットの一つか」を `ltIsBase()` は **`ab` だけ**で訊く。
取り込みが作る文字は `nm` を持ち `ab` を持たないので、前者には「ある」と答え、
後者には「無い」と答える。だから q のスロットは作られず、q と名乗る文字は
無料では隠れる。無料の QWERTY は名前でキーを探す（`kbNamed('q')`）ので、
q のキーは隠れている文字を指している。

## 正しく動いたことの記録

- **描く**。線を引くと［保存］が灰（`rgb(142,136,124)`）から金
  （`rgb(138,106,34)`）に変わる。
- **取り消し・やり直し・全消し**。二本引いて取り消し二回で 0 本、やり直し二回で
  2 本、全消しで 0 本、そのあと取り消しで 2 本が戻る。全部正しい。
- **ラウンド**。一回押すと `on`、もう一回で `off` に戻る。
- **塗り**。`fill:true` が付いた線が保存され、開き直しても残る。
- **保存して開き直す**。線を引いて［保存］→ `ltById('lt.a').st` に 1 本入り、
  `SET.myfont` が true になり、一覧へ戻って開き直しても残っている。網が無いので
  画面はその場に留まり、［保存］は金のまま（2026-09-05 の決定どおり）。
- **描きかけでタブに出て戻る**。線を引いた状態で下のタブでフィードへ出て、制作
  タブから文字→その文字→編集と入り直すと、引いた線がそのまま残っている。
  そこで保存すれば文字に入る。
- **保存せず戻る**。戻る矢印で「Save what you have typed?（はい／いいえ）」が
  出て、文字は書き換わらない。
- **ペンの太さは無い**。`www/glyph.js` の頭に「One pen, everywhere」と書いてある。
  探したが画面にも無い。仕様。
