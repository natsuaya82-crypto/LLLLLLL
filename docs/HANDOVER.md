## 四、直っていないもの

### 1. 保存ボタンが光らない

```
保存ボタンが光らないから押せるのかわからない
くすんだ色から変更したら金になって押せるんじゃないの？
```

文字を描く画面の保存は `www/glyph.js:1028` で `class="navq navsave"` を着て
います。**`www/index.html` に `.navsave` の定義が一つもありません。**
だから色が付かない。`glyph.js` の同じ場所のコメントが「その一行は
index.html のもので、このセッションのものではない」と書いてあり、そのまま
誰も書きませんでした。

仕様は、変更が無い間はくすんだ色、変更があったら金。**角丸・枠・塗りは禁止
（規則18）。文字の色だけ。**

### 2. 設定に飛ばない

オーナーが送ったスクショは **iOS の設定 → 一般 → キーボード → キーボードの
一覧**（Add New Keyboard がある画面）です。

- `kbSettings()`（`www/keyboard.js:3482`）が `LinguaShare.settings` を呼ぶ。
  ネイティブは `ios/App/App/LinguaShare.swift:538`、
  `UIApplication.openSettingsURLString` を開く。
- **`kbSettings()` に無言で終わる枝があります**:
  ```js
  var p=sharePlug();
  if(!p) return;            // ← 何も言わずに終わる
  ```
  橋が無ければ無言、拒否されたときだけ文字が出る。
- どちらも build 130 より前から入っており、`write` は実機で通っています。
  **どこで止まっているかは実機で押さないと分かりません。**

**前のリーダーはここで、押しもせずに原因を三つ並べ、そのうえ「キーボードの
画面にボタンを出す」という頼まれていないものを勝手に足そうとしました。**
オーナーが求めているのは、押したら設定に飛ぶことだけです。
